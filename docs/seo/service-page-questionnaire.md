# サービスページを「依頼前の疑問」に答える形にするための質問票

作成: 2026-09-27。サービスページ 7 本は索引に入っているのに、28 日間の検索表示は合計 8 回でした。「税理士に頼むといくらか」「何をどこまでやってくれるのか」「自分の業種に慣れているか」という依頼前の疑問に、ページが答えていないのが原因です。以下に箇条書きで答えていただければ、私が文章とページ構成に起こします。**分からない項目は空欄で構いません。数値は公開前にもう一度確認します。**

## A. 全サービス共通

1. 初回相談から契約までの流れを、実際の順で教えてください（例: 問い合わせ → 30 分のオンライン面談 → 見積 → 契約 → 資料の受け渡し）。連絡手段（メール・Chatwork・LINE・電話）と、返信の目安もあれば。
2. 対応している会計ソフトと、データの受け渡し方法（freee / マネーフォワード / 弥生 / Excel / 紙のレシート郵送 など）。
3. お断りしている依頼や、得意でない分野があれば（例: 大規模法人、飲食店 など）。
4. 「国税局出身」の具体的な中身のうち、公開してよい範囲（担当していた税目、年数、調査に立ち会った側の経験 など）。
5. お客様の声・事例として書けるもの（匿名化前提。業種、規模感、困っていたこと、頼んだあとどう変わったか）。3 件あると十分です。
6. 料金ページの金額以外に、よく聞かれる料金の質問とその答え（例: 「途中から頼めますか」「記帳を自分でやれば安くなりますか」）。

## B. eBay 輸出・越境 EC（`/services/ebay-export/`）

1. 消費税還付の申告を、これまでどのくらい扱ってきましたか（件数や期間の目安。公開の可否も）。
2. 還付申告の依頼を受けるときの条件（課税事業者であること、帳簿・輸出証明の保存状況 など）と、受けられない典型例。
3. Payoneer・PayPal・eBay の入金データをどう受け取り、どう帳簿に落としていますか（お客様がやること／こちらでやること）。
4. eBay 以外に扱ったことのある越境 EC（Amazon 海外、Etsy、Shopify など）。
5. 「還付までどれくらいかかるか」「税務署から連絡が来るか」など、初めての方が不安に思う点への答え。
6. 料金の目安を、次の形で出せますか: 「還付申告のみ（年 1 回）」「記帳＋還付申告」「顧問契約」。

## C. ネット販売・せどり・フリマ（`/services/online-seller/`）

1. 扱ったことのあるプラットフォーム（Amazon、メルカリ、ヤフオク、BASE、Shopify、楽天 など）。
2. 売上の集計をどこまで代行しますか（各モールの売上レポートの取り込み、在庫の棚卸、返品・手数料の処理）。
3. 副業の方（会社員）と専業の方で、受け方や料金は変わりますか。
4. よくある「頼むきっかけ」（無申告の不安、売上が伸びて消費税が気になる、法人化を考え始めた など）。
5. コンテンツ販売（note・Kindle・オンラインサロン）やアフィリエイトの方も、このページで受けてよいですか。

## D. 決算・確定申告（`/services/tax-return/`）

1. スポット（申告だけ）の受け入れ条件と、締め切りの目安（例: 1 月末までに資料が揃えば対応）。
2. 一人親方・建設業、インフルエンサー・YouTuber の方の申告で、実際によく出る論点や質問。
3. 過去の無申告・期限後申告の相談は受けていますか。

## E. 記帳代行（`/services/bookkeeping/`）

1. 月次の締めの流れ（資料の締切日、こちらからの報告の形）。
2. 美容サロン・小売店で使っている予約システムや POS からのデータ取り込みの経験。

## F. 創業と法人化（`/services/startup/`）

1. 法人化の相談で、判断の目安として実際に使っている考え方（売上・所得の規模、社会保険、消費税の免税期間 など。数値は目安として公開してよいかも）。
2. 設立手続きのうち、事務所で行う範囲と、司法書士など他士業に依頼する範囲。

## G. 相続（`/services/inheritance/`）・税務調査（`/services/tax-audit/`）

1. 相続は今後も日次記事の対象から外し、サービスページと柱記事数本に絞る方針です。ページに足したい情報があれば。
2. 税務調査の立会いで、事前準備として必ずお願いしていること。

回答をいただいたら、各ページに「料金の目安」「依頼の流れ」「対応している業種・働き方」「よくある質問」「事例」を足す構成で下書きを作り、プレビューで確認いただきます。
