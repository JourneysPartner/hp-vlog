# ③相続税シミュレーター 画面仕様書（U5・第1版）

作成日: 2026-08-29
前提: `ui-design.md`（基盤）・`hojinnari-ui-spec.md`（共通パターン）。本書は③固有の差分のみ。
対象: 仕様書 §23〜§31、③サービスの実装済み契約（LEVEL 1/2・小規模宅地は特定居住用1筆・暦年課税の生前贈与加算に対応。相続時精算課税/二次相続は対象外）

## 1. 画面構成

URL `/tools/sozokuzei-simulator/`。

```
[STEP 1 相続人] → [STEP 2 財産と債務] → [LEVEL 1 結果（申告要否）]
 → （もっと詳しく）→ [STEP 3 分割と特例] → [LEVEL 2 結果（税額）]
```

- §24 の2段階をそのまま画面フローにする。LEVEL 1 までは概算評価（路線価×面積等）を許し、LEVEL 2 へ進むときに評価額の直接入力を求める（§27「一次スクリーニング専用」）
- マウント直後からSTEP 1を表示し、導入画面・開始ボタン・所要時間表示は設けない。「入力と計算はこのブラウザ内で完結し、金額を保存・解析送信しません。」をSTEP 1上部に常設する
- ツール専用の純CSSヘッダ/簡素なフッタを使い、共通partialと `main.js` は使わない。ヒーローはSTEP 1では通常表示、STEP 2以降・計算中・停止・結果ではH1を残したまま `.simulator-intro--compact` で縮小しリードを隠す
- STEP・LEVEL結果等への遷移はアプリ領域先頭へのスクロール後、`preventScroll` 付きで新画面見出しへフォーカスする。同一画面の入力エラーはエラー要約へのフォーカスを維持する
- 相続開始日はUI受け入れケースの代表日 `2026-08-29` に固定する（context.inheritanceOpenDate）。この日付に応じた3年ルールをマスターから選択する

## 2. STEP 1 相続人（§25 質問形式）

| 画面項目 | 入力先 | 備考 |
| --- | --- | --- |
| 配偶者はいますか | heirs（spouse 1人を生成） | はい/いいえ |
| お子さまの人数（実子） | heirs（child を人数分生成・id自動採番） | 0〜。実子・養子は別欄 |
| 養子の人数 | heirs（adopted_child） | 税法上の算入制限はサービスが判定。特別養子・配偶者の連れ子養子は「該当の確認」で専門判定へ |
| （子が0人のとき）ご両親・祖父母は | heirs（parent） | 存命の人数 |
| （子・親とも0人のとき）兄弟姉妹は | heirs（sibling_full） | 人数。半血は「該当の確認」へ |
| 該当の確認（まとめて） | — | 子や兄弟で亡くなっている方がいる（代襲）／相続放棄をした・する予定の方がいる／特別養子・連れ子養子がいる／海外在住の方がいる — いずれか該当・不明なら**専門相談の案内**（§25 の複雑ケース誘導。第1版は詳細入力を設けない） |

- 未成年・障害のある相続人の控除は第1版のUIでは扱わない。「該当する方がいる場合、実際の税額はこの試算より少なくなることがあります」を注記（控除なし＝過大側で安全）

## 3. STEP 2 財産と債務（§26・§27）

- 現預金／有価証券／事業用資産／その他財産: 金額欄
- **不動産**（追加式・最大4件）: 種類（土地/建物）→「相続税評価額が分かりますか？」
  - 分かる → 評価額を入力
  - 分からない（土地）→ 路線価（1㎡あたり）×面積㎡。「実際の相続税評価額とは異なる場合があります」を常時表示（§27）。倍率地域・借地/貸家・共有は「該当の確認」で直接入力または専門判定へ
  - 分からない（建物）→ 固定資産税評価額
- 死亡保険金・死亡退職金（追加式）: 受取人（相続人リストから選択／相続人以外）＋金額。「相続人が受け取る分には非課税枠（500万円×法定相続人の数）があります」を補足
- 債務・葬式費用（追加式）: 種類（借入金/未払金/葬式費用/その他）＋金額＋**負担する人**（相続人リストから。§28-1 の4）
- 「相続人が受けた生前贈与はありますか（相続開始前7年以内）」で「はい」の場合、追加・削除式の明細に贈与日、受贈者（相続人のみ）、贈与時の価額、納付した贈与税額（任意）を入力する
- 生前贈与欄には、受贈者は相続人から選ぶこと、相続や遺贈で財産を取得しない人への贈与を含めないこと、「贈与税の配偶者控除を受けた居住用財産の贈与分は金額に含めないでください」、相続時精算課税は下の別質問で回答することを常時表示する
- 相続時精算課税の有無は別質問のままとし、「ある」「わからない」は従来どおり専門相談へ誘導する

## 4. LEVEL 1 結果（§29）

- 申告要否カード（filingNeed）:
  - not_required →「正味遺産額が基礎控除以下のため、**原則として相続税申告は不要**の試算です」
  - possibly_required →「基礎控除を超えるため、**相続税申告が必要となる可能性**があります」
  - required_for_special_rule →「特例の利用により税額は下がりますが、**特例の適用には申告が必要**です（税額0円でも申告不要にはなりません）」（§29・§31）
- 申告要否カードを結果見出し直下の主役ブロックとして扱い、「申告要否（この試算では）」のラベルと判定文言を大きな太字で表示する
- 課税価格の合計と基礎控除（3,000万円＋600万円×法定相続人の数）を数字で併記
- スクリーニング評価を使った場合は概算警告を目立たせる
- 「もっと詳しく（税額まで計算）」→ STEP 3 へ。スクリーニング評価のままなら「評価額の直接入力が必要です」と案内して該当欄へ戻す

## 5. STEP 3 分割と特例（LEVEL 2）

- 分割: 既定「法定相続分で計算（仮）」／「割合を指定」（各人の取得割合を%で。合計100%検証。仮計算の場合は前提表示）
- 未分割・申告期限後の見込みの確認 → 「未分割」なら配偶者の税額軽減が使えない旨の警告つきで計算（§30）
- 小規模宅地等（土地が1件以上あるとき表示）: 対象の土地を1件選択・面積㎡・取得する人（配偶者／同居の親族／その他）・（配偶者以外は）居住継続と申告期限までの保有の見込み — **揃わないときは適用せずに計算**し「適用できる可能性があります（要件の確認は専門相談へ）」を表示（§31「最大として計算しない」）

## 6. LEVEL 2 結果

- 結果見出し直下に「納付税額の合計（この試算では）」＋金額を主役数値として大きな太字で表示する。申告要否カード（LEVEL 1 と同じ規則）と、従来の**相続税の総額**・**納付税額の合計**はそのまま下に併記する
- 各人の表: 取得財産（課税価格）・算出税額・控除（配偶者の税額軽減等）・納付税額（HeirTaxAllocation）
- 各人の控除欄は贈与税額控除を合計へ反映し、適用がある人には内数を表示する。適用順は2割加算後、配偶者の税額軽減前
- 生前贈与加算の内訳として、対象期間の開始日、贈与ごとの対象/期間外、延長期間100万円控除の適用額、受贈者別加算額・贈与税額控除を表示する。期間外は「期間外のため加算されません」と明記する
- 分割割合0%または取得財産0円の相続人への贈与は、安全側として加算し、税額が過大となり得る警告を表示する
- 配偶者の税額軽減: 適用前税額・適用後税額・軽減額を明示（§30）。未分割時は「軽減なしで計算」警告
- 小規模宅地の減額額と適用面積（適用時）。適用しなかった場合は可能性の注記
- 「税額0円≠申告不要」の文言は filingNeed=required_for_special_rule のとき結論カード内に必ず表示
- 警告・前提・計算範囲・根拠・印刷・クリア・相談導線は共通配置。主役ブロックも印刷対象に含める

## 7. その他

- 金額はすべて共通金額欄。面積㎡は整数または小数1桁（Area の分数 Wire へ変換: 小数1桁→ num/10）
- Analytics 共通。公開ページは生成しない（U2〜U4 と同様）

## 8. LEVEL 3 二次相続シミュレーション（§32〜§34。設計 2026-09-03・実装前レビュー用）

### 8-1. 表示条件と配置

- **配偶者が相続人にいる LEVEL 2 の complete 結果でのみ表示**（§32）。LEVEL 1・配偶者なし・blocked では出さない
- LEVEL 2 結果画面の末尾（相談導線の前）に「二次相続もあわせて比較する（LEVEL 3）」の展開セクションを置く。
  追加入力→「二次相続を試算」ボタン→同セクション内に比較結果を描画（ページ遷移なし）

### 8-2. 追加入力（SecondaryInheritanceInput。型は input-type-design.md §6 定義済み）

| 項目 | 必須 | 既定・備考 |
| --- | --- | --- |
| 配偶者の固有財産 | ○ | 配偶者名義の預貯金・不動産等の現在額（概算）。0円可 |
| 二次相続の想定相続人 | ○ | 既定=「一次相続の相続人から配偶者を除いた人数」を自動セット（変更可）。人数と続柄区分（子／子以外）のみ。子以外は2割加算を適用 |
| 二次相続までの想定年数 | 任意 | 空欄なら経年仮定なし |
| 年間生活費 | 任意 | 年数入力時のみ有効 |
| 年間の財産増減率 | 任意 | ▲5%〜+5%程度のセレクト。年数入力時のみ有効 |

- 一次相続で配偶者が取得する割合は入力させない（0%〜100%を10%刻みで自動走査。§32の列挙どおり11点）

### 8-3. 計算仕様

**走査（各割合 X = 0%, 10%, …, 100%）:**

1. **一次相続**: 課税価格の合計額は LEVEL 2 の確定値のまま（小規模宅地等・生前贈与加算・債務控除は入力どおり固定。
   走査で変えるのは取得割合と配偶者の税額軽減だけであり、相続税の総額は不変）。
   配偶者の課税価格＝合計×X、残額は配偶者以外の相続人へ法定相続分の比で按分。
   各人の算出税額・2割加算・税額控除・100円未満切捨ては既存エンジンの §28-1 の順序どおり。
   一次納付合計(X) を得る
2. **二次相続財産の組成**（§32「一次取得分だけを二次相続財産としない」）:
   - S0 ＝ 配偶者固有財産 ＋ 配偶者の一次取得額（課税価格ベース） − 配偶者の一次納付税額
   - 経年仮定あり（年数n）のとき、逐年で S ← (S − 年間生活費) × (1 ＋ 増減率) を n 回適用（各年円未満切捨て）。
     負になったら0円で下限
3. **二次相続税**: 課税価格 S（千円未満切捨て）− 基礎控除（3,000万＋600万×想定相続人数）→
   法定相続分（単一順位につき均等）で仮計算した**相続税の総額**（子以外は総額算出後に2割加算）。
   配偶者の税額軽減・保険非課税・小規模宅地・生前贈与加算・各種控除は二次では適用しない（金額1本の概算）
4. **合計税額(X) ＝ 一次納付合計(X) ＋ 二次相続税(X)**。最小の X を主役表示

**設計判断（レビュー対象）:**

| 論点 | 判断 | 理由 |
| --- | --- | --- |
| 相次相続控除（相法20条） | **第1版では適用しない**。想定年数≤10年かつ一次で配偶者に納付税額があるシナリオには「相次相続控除により二次相続税が下がる可能性」の注記を表示 | 適用しない＝二次過大＝安全側。10年・逓減率の新規マスター登録が必要になるため第2版へ（台帳B-20として登載） |
| 走査の取得割合の基準 | 課税価格ベース | §32の入力例に整合し、一次エンジンの分割指定にそのまま渡せる |
| 経年仮定の式 | 逐年 (S−生活費)×(1＋率)、各年円未満切捨て | 「年初に生活費を使い残りが増減する」説明が平易。§33の概算前提を注記で明示 |
| 二次の各人税額 | 表示しない（総額のみ） | 二次の分割は未確定であり、総額は分割に依存しない |

### 8-4. 結果表示（§34「一次＋二次相続比較」）

- 主役数値ブロック（simulator-key-result）: 「合計税額が最小になる配偶者の取得割合（この試算では）」＋ X% と合計税額
- 11行の比較表: 取得割合／一次相続税（納付合計）／二次相続税（総額）／合計。最小行を強調（色＋「最小」ラベル併記、§61-1）
- 合計税額の**CSSバー表示**（§34のグラフ。外部ライブラリ不可のCSP下のため自前の横棒。印刷にも含む）
- 注記（必ず全件表示）:
  - 「現在の財産額がそのまま二次相続時まで続くと仮定した概算です」（§33の文言義務。経年仮定を入れた場合は仮定内容を併記）
  - 「各割合は遺産分割の可能性・遺留分・換価性を保証しません」（§32）
  - 相次相続控除の注記（該当シナリオがあるとき）

### 8-5. ゴールデンケース（手計算済み・実装時に登録）

前提: 遺産1億円（現金のみ）・相続人は配偶者＋子2人・固有財産3,000万円・経年仮定なし。
一次の相続税の総額 6,300,000円（全シナリオ共通）。

| X | 一次納付合計 | 二次（S0→総額） | 合計 |
| --- | --- | --- | --- |
| 0% | 6,300,000 | 3,000万 ≤ 基礎控除4,200万 → **0** | **6,300,000** |
| 50% | 3,150,000（配偶者は軽減で0） | 8,000万 → 課税遺産3,800万 → **4,700,000** | 7,850,000 |
| 100% | 0（1.6億以下で全額軽減） | 1.3億 → 課税遺産8,800万 → **13,600,000** | 13,600,000 |

経年仮定の単体検証: S0=8,000万・10年・増減率+1%・生活費300万 → S=56,669,263円（逐年・各年切捨て）。
