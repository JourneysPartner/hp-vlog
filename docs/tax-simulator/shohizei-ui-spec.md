# ②消費税シミュレーター 画面仕様書（U4・第1版）

作成日: 2026-08-29
前提: `ui-design.md`（基盤）・`hojinnari-ui-spec.md`（共通パターン）。本書は②固有の差分のみ。
対象: 仕様書 §14〜§22、②サービスの実装済み契約（適用可否判定＋方式比較。輸出還付・返品・旧税率はエンジン第1版対象外）

## 1. 画面構成

URL `/tools/shohizei-simulator/`。

```
[STEP 1 事業者の状況（§15 判定の質問）] → [STEP 2 売上と仕入] → [結果]
```

- マウント直後からSTEP 1を表示し、導入画面・開始ボタン・所要時間表示は設けない。「入力と計算はこのブラウザ内で完結し、金額を保存・解析送信しません。」をSTEP 1上部に常設する
- 免税事業者と判定された場合は STEP 2 へ進まず結果（納税義務なし）へ直行してよい（サービスは免税を complete・比較なしで返す）
- ツール専用の純CSSヘッダ/簡素なフッタを使い、共通partialと `main.js` は使わない。ヒーローはSTEP 1では通常表示、STEP 2以降・計算中・停止・結果ではH1を残したまま `.simulator-intro--compact` で縮小しリードを隠す
- STEP・結果等への遷移はアプリ領域先頭へのスクロール後、`preventScroll` 付きで新画面見出しへフォーカスする。同一画面の入力エラーはエラー要約へのフォーカスを維持する

## 2. STEP 1 事業者の状況（§15）

| 画面項目 | 入力先 | 備考 |
| --- | --- | --- |
| 事業者の区分 | taxpayerType | 個人事業者／法人。3割特例（令和9・10年分・個人のみ）の判定に影響する旨は結果側で表示 |
| 課税期間 | context.consumptionTaxPeriod | 第1版は 2025年（暦年）固定。法人で事業年度が暦年と異なる場合は「対応準備中」の案内 |
| インボイス登録 | eligibility.invoiceRegistration.registered | 済／未／わからない。「済」で登録日（任意）と「登録を機に免税事業者から課税事業者になりましたか」（はい/いいえ/わからない） |
| 基準期間（前々年）の課税売上高 | eligibility.basePeriod | 金額。無い場合は「基準期間がない（開業2年以内など）」チェック。法人は基準期間の月数も（12以外は年換算注記） |
| 特定期間（前年上半期）の課税売上高・給与等支払額 | eligibility.specifiedPeriod | 2欄。どちらかが1,000万円以下なら免税側判定になる旨を補足 |
| 簡易課税選択届出書 | filings（simplified_election） | 提出済み（効力開始年）／未提出／わからない |
| 課税事業者選択届出書 | filings（taxable_person_election） | 提出済み／未提出／わからない。提出済みは2割特例が個別確認（専門判定）になる旨を注記 |
| 該当の確認（まとめて1画面） | newCompany・events・taxablePeriodShortened・specialistChecks | 新設法人（資本金1,000万円以上等）／相続・合併・分割／高額な資産の取得／課税期間の短縮 — いずれか「該当・わからない」で専門判定の案内（§21） |

## 3. STEP 2 売上と仕入（§16・§17）

- 税込／税抜の切替は**欄ごと**（§16。全体一括にしない）。金額欄は共通部品
- 売上: 10%対象の課税売上／8%（軽減税率）対象の課税売上／輸出免税売上（入力があると一般課税は確定額を出せない旨を**入力時点**で表示。§20 は将来対応）
- 仕入: インボイスあり課税仕入（10%／8%）／インボイスなし（免税事業者等から）の課税仕入 — 「ある」場合は 金額・その相手先の年間仕入合計（税込）・帳簿と請求書の保存の3点を1グループで入力（§18 の相手先別上限判定に必要な最小セット。判定できなければ一般課税行が確定にならないことを補足）
- 簡易課税の事業区分（簡易課税の届出がある場合のみ表示・§19）: **ユーザー選択**（自動推定しない）。例示付き文言:
  卸売業【第1種・みなし仕入率90%】／小売業（仕入れた物をそのまま売る。ネット物販含む）【第2種・80%】／製造業・建設業【第3種・70%】／飲食店業など【第4種・60%】／サービス業・コンサルタントなど【第5種・50%】／不動産業【第6種・40%】／複数の事業・わからない → 専門判定の案内（複数事業の特例計算は対応準備中）

## 4. 結果画面（§22）

1. **利用できる方式**（判定リスト）: 4方式を○（利用可能）／×（対象外・理由）／？（入力不足・不足項目）／—（判定不能・専門判定）で表示。×の理由は文言で（例:「法人のため3割特例の対象外です」）
2. **納税額の比較**: eligible かつ計算できた方式だけ金額を並べる（§22。対象外の方式に金額を並べない）。昇順
3. **結論**: 「今回の入力条件では、**○○が最も納税額の少ない試算**となりました。」＋一般課税との差額（一般課税が確定できた場合のみ「▲○円」。確定できない場合は差額を出さない・§22）
4. 簡易課税が届出未提出で ineligible の場合: 「選択届出書を提出すると簡易課税を選べる可能性があります（提出期限は原則、適用したい課税期間の開始前日まで）」の案内
5. **免税の場合**: 「基準期間・特定期間の状況から、納税義務がない（免税事業者）試算です。インボイス登録した場合の比較は、登録済みとして再計算してください」
6. 警告・前提・計算範囲・根拠・印刷・クリアは①④と同じ配置。輸出売上があるときは除外項目に明示
