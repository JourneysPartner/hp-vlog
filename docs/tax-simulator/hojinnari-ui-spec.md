# ①法人成りシミュレーター 画面仕様書（U2・第1版）

作成日: 2026-08-29
前提: `ui-design.md`（配信・ビルド・セキュリティ・a11yの基盤はそちらに従う。本書は①の画面固有仕様）
対象: 仕様書 §5・§6・§8〜§13・§61・§61-1、①サービス（src/simulators/hojinnari/）の実装済み契約

## 1. 画面の全体構成

URL `/tools/hojinnari-simulator/`。1ページアプリで、次の3状態を持つ。

```
[導入] → [入力STEP 1〜3] → （追加質問・入力不足の解消） → [結果]
```

- **導入**: ツール名・1行説明・免責（§3-4 の位置付け文）・「かんたん計算をはじめる」ボタン。所要目安（3分程度）を表示
- **入力STEP**: 下記 §3。STEP表示は「STEP n / 現時点の総STEP数」をテキストで（§61-1）
- **結果**: 下記 §5。再計算・入力に戻る・入力をクリア・印刷を常設
- 第1版は**かんたん計算のみ**提供する。`precision` 切替UIは置かず `"simple"` 固定で送る（サービスは simple/detailed 同一計算。詳細計算タブは対応範囲拡張（deferred B-1/B-7）と同時に追加する）。「かんたん」の呼称は §5 のとおり画面に表示するが、精度の一語評価はしない

## 2. デザイン言語（既存サイトに従う）

`assets/css/style.css` のトークンをそのまま使う。新しい色・書体を発明しない。

- 紺 `#0B2045`（見出し・強調）／オレンジ `#E85320`（主ボタン・アクセント）／本文 `#22293a`・補足 `#55607a`
- 背景: 白・`#F5F7FA`（比較表の個人事業列など）・`#FDF0EA`（法人化列の強調・オレンジ淡）
- 罫線 `#E3E8F0`・角丸 8/12px・影 `--shadow-sm`
- 書体: Noto Sans JP（本文・見出しとも。サイトのh要素既定に合わせる）。ツール見出しの飾りに Zen Old Mincho を使ってよい（`.section-heading` と同格の扱い）
- 有利・不利は色だけで表さない（§61-1）: 差額には「＋」「▲」と文言を併記

## 3. 入力STEP（かんたん計算）

§9 のかんたん項目に、①サービスが必須とする確認項目を統合し3STEPにする。全金額欄は `ui-design.md` §4 の金額入力仕様（文字列・全角/万対応・確認表示・autocomplete off）。

### STEP 1 事業の状況（個人事業side）

| 画面項目 | 型 | 入力先（Wire） | 備考 |
| --- | --- | --- | --- |
| 計算対象年 | 選択（対応年のみ） | context.incomeTaxYear ほか年度系 | 第1版は 2025（令和7年分）固定表示でよい |
| 年間売上高 | 金額 | individual.business.revenue（暦年1セグメント） | |
| 年間経費 | 金額 | individual.business.expenses（同上） | 「役員報酬を除いた事業経費」を欄外注記（§9）。加えて「ご家族に専従者給与を支払っていて、その方が法人化後に役員になる予定の場合は、その専従者給与も除く」ことを明記（2026-08-29 税理士レビュー反映。法人側へ経費をそのまま写すため、役員報酬となる支払いを経費に残すと二重計上になる） |
| 経費の確認 | チェック必須 | expensesExcludeSocialInsuranceAndMutualAid: "yes" | 文言「経費に国民健康保険料・国民年金・小規模企業共済等の掛金を**含めていません**」。未チェックは先へ進めない（HJ_EXPENSES_EXCLUSION_CONFIRMATION_REQUIRED の事前解消） |
| 青色申告 | 選択: 65万円控除（e-Tax）/ 55万円 / 10万円 / 青色だが控除なし / 白色 / わからない | blueReturn | 「わからない」を選ぶと §4 の案内（判定できない旨と確認方法）を表示して停止 |
| 事業の種類 | 選択（素人にも判別できる例示付き文言・2026-08-29 税理士レビュー反映）: 物品販売（ネット販売・輸出を含む）・製造・飲食・請負・不動産貸付など【第1種・5%】／畜産・水産など【第2種・4%】／医療・士業・コンサルタント・デザインなどの自由業【第3種・5%】／あん摩・マッサージ・はり・きゅう・柔道整復など【第3種・3%】／上のどれにもあてはまらない（文筆業・画家・音楽家など → 個人事業税なし）／わからない | business.businessTaxCategory | 3%区分の値は `type3_reduced`（列挙値と画面値のずれを再発防止テストで固定）。「わからない」は §4 案内 |

| --- | --- | --- | --- |

### STEP 3 法人化の想定（法人side）

| 画面項目 | 型 | 入力先 | 備考 |
| --- | --- | --- | --- |
| 役員報酬（月額） | 金額 | corporate.officerCompensation（12か月同額プラン） | 「いくらにすればいいか分からない」リンク → ④へ（§13。第1版はリンクのみ・遷移先が未公開の間は非表示） |

- 「計算する」で Wire を組み立て `validate` → エラーは §61-1 どおり上部要約＋各欄。ok なら `simulate`
- 計算中は `role="status"` で通知・ボタン `aria-disabled`。完了で結果見出しへフォーカス移動

## 4. 追加質問・停止（blocked）の表示

サービスの blocked は理由コード→画面文言カタログで変換する。かんたん計算のUIは上記STEPで大半のコードを**事前に発生させない**設計だが、到達しうるものは次のとおり。

| 理由コード | 画面での扱い |
| --- | --- |
| HJ_BLUE_RETURN_STATUS_UNKNOWN / HJ_BLUE_RETURN_DEDUCTION_CATEGORY_REQUIRED | 「青色申告の控除区分が確認できないため計算を止めました。確定申告書の控えの『青色申告特別控除額』をご確認ください」＋選択欄再表示 |
| HJ_BUSINESS_TAX_CATEGORY_REQUIRED / _UNKNOWN | 「個人事業税の業種区分が確認できないため計算を止めました。都道府県税事務所の納税通知書で確認できます」＋選択欄再表示 |
| HJ_NHI_SELECTION_REQUIRED / HJ_NATIONAL_PENSION_SELECTION_REQUIRED | 該当STEPへ戻し選択を促す |
| NHI 登録外自治体（概算選択） | 「お住まいの自治体の料率は未登録のため、実際の年間保険料の入力をお願いします」 |
| IT_BUSINESS_LOSS_OFFSET_UNSUPPORTED（売上＜経費） | 「事業所得が赤字となるため、このシミュレーターでは比較できません（損益通算は対応準備中）」＋専門相談導線 |
| HJ_SPECIALIST_PROFILE_UNSUPPORTED ほか対象外系 | 「この条件はシミュレーターの対応範囲外です」＋事務所への相談導線（§68-1 の専門判定） |
| カタログ未登録のコード | 原文メッセージをそのまま表示＋相談導線（無言で握りつぶさない） |

- blocked 表示は `role="alert"`（1回）。解消可能なものは該当入力欄へのリンクを付ける

## 5. 結果画面

上から順に:

1. **結果見出し**（フォーカス先・§61-1）: 「試算結果（2025年分・平年度比較）」＋結果状態（complete/partial）
2. **結論カード**（§6）: 断定しない定型文。例:
   「本シミュレーションの入力条件では、**法人化した場合のほうが年間 約81万円 手残りが増える**試算となりました。」
   併記（§11）: 個人事業の手取り／法人化後に個人が使える資金／法人に残る資金／税・社会保険の合計負担（両者）。直下に警告文（§11 そのまま）「法人内部に残る資金は社長個人が自由に使える資金ではありません。」
   設立・維持コスト未入力時: 「法人設立・維持費用（登記・税理士報酬等）は含まれていません」
3. **比較表**（§11 の9行）: 所得税／住民税／個人事業税／法人税等／本人社会保険／会社社会保険（内訳表示のみ・合計へ再加算しない注記）／個人手取り／法人税引後利益／法人＋個人手残り。該当しない欄は「―」、0円と区別（§11）。差額列に＋/▲併記
4. **消費税**: バッジ「消費税：比較対象外」（§12）＋除外項目一覧（partial 時は理由付き）
5. **計算範囲**（§5）: 「計算済み n / 対象 m 項目」＋内訳（直接入力／制度既定値／概算（国保）／除外）。対象項目カタログは①で固定（所得税・復興税・住民税・個人事業税・国保・国民年金・法人税・地方法人税・法人住民税・法人事業税等・社会保険・消費税）
6. **警告・前提**: §61 の level 別（critical→attention→info）。前提（assumptions）は折りたたみで全文
7. **根拠**: 計算版・マスタースナップショットID・法令基準日・出典一覧（§7・§59）
8. **アクション**: 役員報酬の最適化へ（④導線・§13）／結果を印刷・PDF保存（§59）／入力を修正する／入力をクリア（§57-1）／個別相談の案内（リンクのみ。金額送信はしない・§57-3 未実装のため）

- partial（法人所在地が違う等）: 結論カードに「概算の前提が含まれます」を明示し、除外項目を4の位置で表示
- 再計算時は旧結果を破棄して見出しへフォーカス（§61-1）
