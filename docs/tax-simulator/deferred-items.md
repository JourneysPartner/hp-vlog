# 税務シミュレーター 残課題台帳

作成日: 2026-08-28（4サービス第1版完成時点・PR #492 / #495 / #496 / #497 マージ後）

この台帳は、第1版で意図的に対象外とした項目・将来対応が決まっている項目を一覧化する。
**すべての対象外は理由コード付き `blocked` または前提の明示（assumptions）で安全側に倒してあり、
誤った確定額を出す形の欠落は無い**（review-summary.md の方針の継続）。

優先度は事務所の顧客層（越境EC・eBay輸出セラー、法人成り検討者、相続相談）を踏まえた提案であり、
着手順は都度判断する。

- P1: 顧客価値が大きい・制度上頻出・期日がある
- P2: 主要ユースケースの拡張
- P3: 網羅性の拡充（急がない）
