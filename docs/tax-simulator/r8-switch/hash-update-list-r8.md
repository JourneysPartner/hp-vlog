## 2. 調べ方

1. `node scripts/check-master-freshness.js --as-of 2026-10-28 --json` で「出典が更新された」148 件を取り出した（ほかの警告は 0 件: 控え未記録・blocked・未承認とも 0）。
2. 出典ページごとに、控えの版と今の版の本文（`data/nta-sources/taxanswer/<分類>/<番号>.json` の `body`）を、空白を除いて文ごとに並べ、増えた文・消えた文を出した。
3. 消えた文・増えた文に、記録の金額・率・境目・期間に関わるものがあるかを読んだ。**金額の行が差に出てこない＝その金額は変わっていない**、と判断している。
4. 所得税の 9 ページ（1199・1410・1180・1191・1195・1177・1171・1175・1140）は、比較表（`comparison-income-r8.md`）で表まで読んである。今回も同じ方法で差を取り、比較表の判定と合うことを確かめた。
5. A に入れた記録について、ほかのページで令和9年分以後の改正が告知されていないかも確かめた（No.2270 特定の基準所得金額の課税の特例、No.2072 青色申告特別控除に「令和9年」の記述なし）。

限界: AI の 1 回の読み取り。国税庁のページが二次の資料であることは変わらない（一次資料の照合は段 2 以降）。ここで確かめたのは「控えの版から今の版への変化が、その記録に及ぶか」だけ。

### 全ページに共通する差（値に関係しないもの）

- 見出し「令和7年4月1日現在法令等」→「令和8年4月1日現在法令等」
- お問い合わせ先の定型文（「国税局電話相談センター等で行っていますので…」→「税についての相談窓口をご覧ください。」）
- 表記: 全角数字→半角、「％」→「パーセント」（消費税）、「及び／又は」→「および／または」
- 根拠法令の号のずれ（例: 措令26の27の2→26の27の3、障害者総合支援法の第17項→第18項）
