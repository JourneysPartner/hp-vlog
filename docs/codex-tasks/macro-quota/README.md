# 相続・贈与の記事の割合を決め、実際に守らせる（macro-quota）

## 背景（2026-10-27）

- 毛利さんの決定（2026-10-27）: **相続・贈与を日次記事の対象にする。ただし割合をはっきり決める**。これまでの方針（`docs/seo/service-page-questionnaire.md` G-1「相続は日次記事の対象から外す」）を改める。
- 割合は **10%**（週 3 本 × 約 4.3 週 ＝ 月 13 本の 1 割 → **直近 30 日で 2 本まで**）。理由は 2 つ。
  - 9/15〜10/26 にフォームで届いた問い合わせはほぼ全部が物販（eBay・EC）で、相続の問い合わせは見当たらない。
  - 相続の記事は検索での表示がほぼ無い（狙った語の順位も「表示なし」）。
- 実態: `data/macro-target-ratios.json` の「相続贈与」は 0.02 なのに、直近 30 日に公開した記事 5 本のうち 3 本（60%）が相続・贈与だった。承認待ちの下書きにも #690・#698 がある。

## 原因（コードで確認済み）

1. `scripts/lib/topic-selector.js` は「需要の証拠 > 季節 > 問い合わせ近接度」で並べ、**偏りの点数（balance）は同点の時しか使わない**。そのため目標比率はほぼ効かない。
2. 強い上限（`category-balance.js` の `hardCapFor`）は、直近 7 日だけを見て、しかも直近 14 日が 4 本以上の時しか働かない。週 3 本の今のペースでは、ほとんど発動しない。
3. 比率の集計（`computeMacroRatios`）は main の記事だけを数え、**承認待ちの下書きを数えない**。そのため、未承認の相続の下書きがあっても、また相続を選ぶ。

## 方針

- 目標比率の表は 1 か所（`data/macro-target-ratios.json`）のまま使う。「相続贈与」を 0.10 にし、合計が 1.00 になるように他を調整する（下表）。
- 「本数の上限を必ず守る分類」を設定ファイルで指定できるようにし、まず「相続贈与」だけを指定する。上限を超える候補は選ばない（同点の判定でなく、候補から外す）。
- 数えるのは、main の記事と承認待ちの下書きの両方。

## 厳守事項

- 手動の生成（`force_slug`）は上限の対象外のまま（人が決めて出すものなので）。
- 記事本文（`content/posts/*.md`）と、承認・公開の流れは変えない。記事の承認は今までどおり手動。
- 上限で外した候補は、「候補が全部外れたら外したものを戻す」既存の救済で**戻さない**（戻すと上限が漏れる）。

## 元に戻す方法

この PR を revert する（設定ファイルを消すと上限は働かず、比率も元に戻る）。
