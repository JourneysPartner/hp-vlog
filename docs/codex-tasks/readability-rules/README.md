# 記事の書き方に「読みやすい日本語」の決まりを足す

## 背景

- 2026-10-26 に毛利が、AI の書いた日本語を読みやすく直すスキル yomiyasu（ALGO ARTIS、MIT ライセンス）を記事生成に組み込めるか尋ねた。
- yomiyasu の本体（指示書 43,482 字）は、対話する AI が自分で検査を回し、利用者に問い返す前提で作られている。日次生成は AI に 1 回頼んで答えを受け取る作りなので、本体はそのまま入らない。
- 400〜500 字の短い版 yomiyasu-pocket（`nanaism/yomiyasu-pocket`、commit `c42712c4f79b1b66c06c2b63404d0f6692d46134`）の決まりを、**書く時点の指示**に直して足すことを毛利が決めた（2026-10-26）。
- 書いた後にもう 1 回推敲させる案（別の AI 呼び出し）は今回やらない。

## いまの記事の様子（2026-10-26 時点、`content/posts/` 280 本）

| 癖 | 含む記事 |
|---|---|
| ダッシュ「——」 | 77 本 |
| 「重要なのは」 | 23 本 |
| 行末のコロン「：」 | 18 本 |
| ダッシュ「―」 | 5 本 |

ダッシュは、固定ルールのリード文の例（`article-prompt-static.js` の「冒頭の型」）が「——」で文をつないでいて、書き手の AI がそれをまねていると見られる。直近の記事でもリード文に出ている。

## 方針

- 決まりは定数 1 つ（`READABILITY_RULES`）にまとめ、新規の記事生成（固定ルール `STATIC_RULES`）と、差し戻しの全文書き直し（`regenerateWithContentModel` の指示）の両方で同じものを使う。
- 固定ルールの中に置く（毎回変わる部分には置かない）。指示の前半が毎回同じなら、書き手の AI の入力の再利用（キャッシュ）が効く。
- 正確性のルール（出典・数値・条件・例外）と穏当な言い方のルールを優先すると、決まりの先頭に書く。読みやすさのために条件や例外を削らせない。
- リード文の例からダッシュを外す。

## 段階

| 段階 | 内容 | 指示書 |
|---|---|---|
| 1 | 決まりの定数を作り、生成と差し戻しの指示に入れる。リード文の例を直す。試験 | `01-writing-rules.md` |

## 全段階共通の厳守事項

- 変えるのは `scripts/lib/article-prompt-static.js`・`scripts/generate-draft.js`（差し戻しの指示の文体の節だけ）・新しい試験ファイルだけ。
- 書き手のモデル・事実照合・承認の流れ・字数の受入・論点別ルールは変えない。
- `content/posts/`・`data/` は触らない。既存の記事は直さない（今後の生成だけが対象）。
