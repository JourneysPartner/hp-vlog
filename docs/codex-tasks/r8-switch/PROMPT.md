## 進め方

- 作業ブランチは現在チェックアウト済みの `r8/c16-nhi-prior-rate` です。ブランチを切り替えないでください。
- この環境では git にコミットできません。変更と確認まで行い、コミットはしないでください。push と PR も別の担当が行います。
- 指示書の R1〜R5 を順に満たし、「確かめること」の 1〜5 を実行してから最終報告してください。
- 迷ったら README の「全段階共通の厳守事項」と指示書の「決めたこと」「変えてはいけないもの」を優先し、判断が必要な点は変更せずに最終報告に【要判断】として書いてください。

- Windows です。Git Bash が `CreateFileMapping ... error 5` で落ちることがあります。その場合は PowerShell か cmd を使ってください。ファイルは LF・UTF-8（BOM なし）で書いてください。PowerShell の `Set-Content`/`Out-File` は使わないでください。
- この環境では子プロセスで node・git・bash を起動する試験が EPERM で落ちることがあります。その場合は落ちた試験名とエラーの 1 行目だけ報告してください。別の担当が環境の外で再実行します。

## 厳守

- 金額・率・境目・期間・`legal_status`・`data_review_status` を変えない。マスターの JSON は 1 文字も変えない。
- `SUPPORTED_YEAR` と画面の年を変えない。
- 指示書の「変えてはいけないもの」に書いたファイル・項目を変えない。
- 公開用のまとめファイル（`assets/js/tax-simulator.*.js`・`tax-simulator-manifest.json`・`tax-simulator-boot.js`）は、試験で書き換わったら元に戻す。消えたファイルも戻し、新しくできたファイルは消す。
- 試験を弱めない・消さない・飛ばさない。今の試験が落ちるときは、仕様どおりの変化か不具合かを見分け、仕様どおりの変化なら理由を最終報告に書く。

- 説明・最終報告は日本語。
