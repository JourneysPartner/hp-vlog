## 進め方

- 作業ブランチは現在チェックアウト済みの `r8/stage1-source-hash` です。ブランチを切り替えないでください。
- この環境では git にコミットできません。変更と確認まで行い、コミットはしないでください。push と PR も別の担当が行います。
- 指示書の R1〜R5 を順に満たし、「確かめること」の 1〜6 を実行してから最終報告してください。
- 迷ったら README の「全段階共通の厳守事項」と 01 の R5 を優先し、判断が必要な点は変更せずに最終報告に【要判断】として書いてください。
- ネットワークは使えません。`npm install` は済んでいます。
- Windows です。Git Bash が `CreateFileMapping ... error 5` で落ちることがあります。その場合は PowerShell か cmd を使ってください。ファイルは LF・UTF-8（BOM なし）で書いてください。PowerShell の `Set-Content`/`Out-File` は BOM や CRLF を入れることがあるので、書き込みは node で行ってください。
- この環境では子プロセスで node・git・bash を起動する試験が EPERM で落ちることがあります。その場合は落ちた試験名とエラーの 1 行目だけ報告してください。別の担当が環境の外で再実行します。
