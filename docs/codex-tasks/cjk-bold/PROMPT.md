## 進め方

- 作業ブランチは現在チェックアウト済みの `fix/cjk-bold-render` です。ブランチを切り替えないでください。
- **コミットはしないでください。** この環境は隔離されていて `.git` に書けません。変更は作業ツリーに残してください（コミットは別の担当が行います）。
- 指示書の R 番号の順に満たし、最後にテストを流してください。
- 迷ったら指示書の「変更してはいけないもの」を優先し、判断が必要な点は実装せずに最終報告に【要判断】として書いてください。
- ネットワークは使えません。`npm install` は済んでいます。
- Git Bash が落ちる場合は PowerShell か cmd を使ってください。
- 既存ファイルの改行コード（LF／CRLF）は元のまま保ってください。
- push と PR 作成はしないでください。

## 厳守

- `content/posts/*.md` は 1 本も変えない。
- 公開ページに新しい JavaScript を足さない。
- 鍵・トークンをログやファイルに出さない。
- 説明・コメント・最終報告は日本語。

## 完了時に実行して結果を報告するもの

```
npm run build
npm run validate
node scripts/lib/__tests__/test-cjk-bold.js
node scripts/lib/__tests__/test-consolidation.js
git status --short
```

（隔離内では子プロセスの起動が EPERM で失敗するテストがあります。その場合は失敗したテスト名とエラーをそのまま書いてください。）
