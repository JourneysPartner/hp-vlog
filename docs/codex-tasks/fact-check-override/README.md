# 照合で止まった記事を、人の判断で公開できるようにする

2026-11-06 の決定。日次記事「一人親方の白色申告と青色申告どっちを選ぶ？」（PR #744）で、利用者が「このまま公開」を押しても照合（事実の照合）が承認を止めた。利用者の判断は「そのレベルで、私が承認しても承認にならないのはやりすぎ」。

## 何が起きていたか

- 承認の処理（`netlify/functions/review-approve-background.js` 365 行付近）は、照合の状態が `revise` なら必ず止める。人が上書きする道が無い。
- 照合で止まると、`applyFactResult`（`scripts/lib/fact-check.js` 1735 行付近）が `recommendation` も `revise` に書き換える。このため、承認の品質ゲート（同 461 行）・公開の直前の確認（`scripts/publish-due.js` の `publishGateReasons`）・検証（`scripts/validate.js` 178 行）も、それぞれ別に止める。
- #744 の止まった理由は 2 つ。
  1. 照合の AI が箇条書き「10万円：上のいずれにも当てはまらない場合」から主張を抜き出したとき、本文の文を写さずに要約を書いた。このため「本文に見つからない」で捨てた主張になり、数字の主張なので承認を止めた。記事の誤りではなく、照合自身の読み取りの失敗。
  2. 見出し「赤字が3年繰り越せるのは青色だけ」が言い過ぎ（白色でも変動所得・被災事業用資産の損失は繰り越せる）。照合は本文の文を直したが、見出しは直せず、「直した後もまだ食い違う」で止まった。
- 2026-10-16 以降に照合した記事 9 本のうち 5 本が一度は承認不可。そのうち 4 本は「捨てた主張」（照合の読み取りの失敗）が理由に含まれ、#698 はそれだけが理由だった。

## 決定（2026-11-06 利用者）

1. **人の最終判断を優先する。** 照合で止まった記事も、レビュー画面で「照合の指摘を確認しました」に印を付けて「このまま公開」を押せば公開できる。誰がいつ上書きしたかを記録する。照合の指摘は消さずに画面に出す。
2. **照合自身が本文の文を特定できなかった主張（捨てた主張）では止めない。** 承認は止めず、「人が確かめる箇所」に載せる。

段階 1 の要件は `01-override.md`、段階 2 の要件は `02-discarded-not-blocking.md`。

## 全段階の厳守事項（安全の決まり）

- **S1 黙って通さない。** 画面で印を付けた承認の要求（`fact_check_override: true`）が無ければ、今と全く同じに止める。印の無い要求で照合の止めを外す道を作らない。
- **S2 見た版だけに効く。** 上書きは、人が画面で見た記事ファイルの版（GitHub のファイルの sha）と、承認の時点の枝のファイルの sha が一致するときだけ効く。一致しなければ承認せず、「内容が変わったので画面を開き直してください」と通知する。差し戻しの再生成と承認が行き違っても、見ていない版を公開しない。
- **S3 外すのは照合の止めだけ。** 出典ガード・仮置きタイトル・公開済み記事の保護・`recommendation` が `reject`・各スコアの低さ・照合より前から `revise` だった記事（`fact_check_prev_recommendation` が `revise` か `reject`）は、上書きしても今までどおり止める。
- **S4 記録を残し、照合の結果は書き換えない。** 上書きで承認した記事には、上書きした日時・そのときの照合の状態と要約・見た版の sha を残す。`fact_check_status`・`fact_check_summary`・`fact_check_blocking` と照合の記録（`data/fact-check/*.json`）は変えない（「照合 ok」に見せかけない）。
- **S5 古い上書きを使い回さない。** 新しい照合の結果を記事に書くとき、上書きの記録は消す。上書きの判断は、保存された欄ではなく、その時の承認の要求（S1・S2）でだけ行う。
- **S6 機械が書いた文は今までどおり止める。** 段階 2 で止めなくなるのは、書き手（記事を生成した AI）の文から抜き出した主張だけ。照合の自動修正で置き換えた文（再照合の段階）の捨てた主張は、今までどおり止める。

## 元に戻す方法

- 段階 1・2 とも、この PR を戻せば元の動きに戻る。記事に残る上書きの欄は、戻した後のコードでは読まれない（害は無い）。
- 段階 2 は `LOGIC_VERSION` を上げる。戻すと次の照合から元の判定に戻る。

## 受け入れ確認（Claude）

- 指示書の試験がすべて通り、関係する既存の試験も通る（隔離の外で流し直す）。
- S1〜S6 をそれぞれ試験で確かめている。

- レビュー画面: 照合で止まっているときだけ確認欄が出て、印を付けるまで「このまま公開」が押せない。止まっていない記事の画面は変わらない。
