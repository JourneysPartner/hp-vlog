## 要点

軽減税率Q&A の PDF は、節ごとに全角と半角を使い分けています。
「飲食料品の範囲」は `問１`〜（全角）、それ以降の節は `問1`〜（半角）で番号が振り直されます。

ファイル名を作るときに全角を半角へ揃えているため、`問４` と `問4` がどちらも
`jirei-4` になり、**後から書いたほうが勝って**います。消えた側の見出しは index に残るので、
**index の表題とファイルの中身が食い違います**。

いま4件の本物の答えが失われています。

```
問１「軽減税率制度」の概要（1,410字）
問３ 水産物の販売（245字）
問４ 家畜の飼料、ペットフードの販売（195字）
問８ 水の販売（316字）
```

`scripts/lib/nta-qa.js` は index の title とファイルの body を組にして記事生成へ渡すので、
**表題と中身がずれた Q&A がそのまま記事に渡ります**。

## 満たしてほしいこと

1. 同じ実行の中で、別の問が同じ id にならない
2. **実行のたびに id が変わらない。** pdftotext の読み順は実行ごとに変わるので、
   「先に出てきたほうが素の名前」のような順序依存の決め方はしないでください
3. **いまある半角の id は変えない**（`jirei-4` はそのまま）。差分を小さく保つため
4. ファイル名は ASCII だけ。`jirei-４.json` は `jirei-4.json` と見分けがつかず危険です

推奨は「全角で書かれた問番号に印を付ける」です（全角か半角かは組版で決まり、
取得のたびに変わらないので安定します）。印の文字は任せます。
