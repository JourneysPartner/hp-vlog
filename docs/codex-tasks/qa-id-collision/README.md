# 別の問が同じファイルに潰れている

## 何が起きているか

国税庁Q&A のまとめ PDF を問ごとに切り分けるとき、**別の問が同じファイル名になり、
片方が上書きで消えている**。消えた側の見出しは index に残るため、
**index の表題とファイルの中身が食い違う**。

軽減税率Q&A で4組。いずれも中身のある完全な答えが失われている。

| ファイル名 | 残っているもの | 消えているもの |
|---|---|---|
| `keigen/gaiyo-1` | 問1 仕入先から受け取った請求書等…の追記（780字） | **問１ 「軽減税率制度」の概要（1,410字）** |
| `keigen/jirei-3` | 問3 通信販売（484字） | **問３ 水産物の販売（245字）** |
| `keigen/jirei-4` | 問4 販売奨励金（731字） | **問４ 家畜の飼料、ペットフードの販売（195字）** |
| `keigen/jirei-8` | 問8 有料老人ホームの飲食料品の提供（2,169字） | **問８ 水の販売（316字）** |

消えている4件はいずれも「飲食料品の範囲」という当ブログの中心論点で、
原文を確認済みの本物の答えである。

```
問８ 水の販売（316字・実物）
  （水の販売） 問８ 水の販売は、軽減税率の適用対象となりますか。【令和５年 10 月改訂】
  【答】 「食品」とは、人の飲用又は食用に供されるものをいいますので、…
  いわゆるミネラルウォーターなどの飲料水は、「食品」に該当し、その販売は軽減税率の
  適用対象となります。他方、水道水は、炊事や飲用のための「食品」としての水と、…
```

## なぜ起きるか

**PDF が節ごとに全角と半角を使い分けている。** 個別事例編の「飲食料品の範囲」は
`問１`〜（全角）、それ以降の節は `問1`〜（半角）で始まり、番号が振り直される。

ファイル名を作るときに全角を半角へ揃えているため、`問４` と `問4` が
どちらも `jirei-4` になる。

```js
// scripts/crawl-nta-qa.js  crawlSource の中
const slugNo = part.qNo
  .replace(/[０-９]/g, (c) => String.fromCharCode(c.charCodeAt(0) - 0xFEE0))
  .replace(/[^0-9-]/g, '');
const sub = { id: `${doc.id}-${slugNo}`, title: part.title };
```

分割関数側の重複排除は生の `qNo` で見ているので `問４` と `問4` は別物として通る。
ファイル名の段階で初めて衝突し、**後から書いたほうが勝つ**。

さらに、`saved` には両方が積まれるので index にエントリが2つでき、
片方はファイルの中身と対応しない。

```
index の keigen: 138 件
ファイル:        134 件   ← 4件ぶん多い
```

## 実害

`scripts/lib/nta-qa.js` の `readBody(entry)` は `entry.file_path` を読み、
`entry.title` と組にして返す。**表題と中身がずれた Q&A がそのまま記事生成に渡る。**

「軽減税率制度の概要」という表題で「請求書への追記」の本文が渡る、という状態。
先に直した通達のすり替わり（#605）と同じ形。
