# 記事の書き方に「やわらかい言葉と、書きすぎない細かさ」の決まりを足す

## 背景

- 2026-11-02 の日次記事（PR #737「YouTuberの税金はいくら？払い方と確定申告の判断基準」）を毛利が読み、全体に「固すぎる」と感じて、次の 4 点で差し戻した。
  1. 「ふと手が止まるのが税金の扱いです」→「気になるのが税金です」
  2. 見出し「判断の分岐：自分はどこに当てはまるか」→「自分はどれに当てはまるか」
  3. その節の表にあった「確認先」（行ごとにタックスアンサーの番号を並べた列）は要らない
  4. 所得控除を 16 種類すべて並べた文は書きすぎ。半分くらいでよい
- 差し戻しはその記事にだけ効く。毛利は同日、この 4 点から Claude がまとめた決まりを「今後のすべての記事の書き方に反映させて」と決めた（2026-11-02）。

## いまの記事の様子（2026-11-02 時点、`content/posts/` 281 本）

| 癖 | 含む記事 |
|---|---|
| 「手が止ま」 | 23 本 |
| 本文の「確認先」 | 3 本 |

「手が止まる」は、固定ルールのリード文の例（`article-prompt-static.js` の「冒頭の型」）に「決算の直前になって手が止まる方は少なくありません。」とあり、書き手の AI がそれをまねていると見られる（前回の読みやすさの決まり #707 で直したダッシュと同じ型）。

## 方針

- 決まりは新しい定数 1 つ（`PLAIN_WORDING_RULES`）にまとめ、今の読みやすさの決まり（`READABILITY_RULES`）の直後に置く。新規の記事生成（固定ルール `STATIC_RULES`）と、差し戻しの全文書き直し（`regenerateWithContentModel`）の両方で同じものを使う。
- `READABILITY_RULES` の本文は変えない（yomiyasu-pocket 由来で、MIT の出どころを書いた定数のため。毛利の決まりと混ぜない）。
- 部分の書き直し（節の修正・節の追加・最小修正・複数箇所の修正）と更新案には入れない。`READABILITY_RULES` と同じ理由（対象外の節まで文体が変わり、短縮の見張りに当たるおそれ）。
- 正確性のルール（出典・数値・条件・例外）を優先すると決まりの先頭に書く。列挙を減らす決まりは「種類の紹介」に限り、対象かどうかを決める列挙は削らせない（出典の本文ブロックの「対象範囲は本文の列挙をそのまま守る」と食い違わせない）。
- リード文の例から「手が止まる」を外す。
- 「手が止ま」を禁止表現（`data/banned-phrases.json`）に、置換なし（警告だけ）で足す。書き手への指示にも禁止表現として載る。

## 段階

| 段階 | 内容 | 指示書 |
|---|---|---|
| 1 | 決まりの定数を作り、生成と差し戻しの指示に入れる。リード文の例と構成テンプレートの注記を直す。禁止表現を 1 件足す。試験 | `01-plain-wording-rules.md` |

## 全段階共通の厳守事項

- 変えるのは `scripts/lib/article-prompt-static.js`・`scripts/generate-draft.js`（差し戻しの全文書き直しの指示の、文体の節の直後だけ）・`data/banned-phrases.json`（1 件の追加だけ）・試験ファイルだけ。
- 書き手のモデル・事実照合・承認の流れ・字数の受入・論点別ルール・題名のルール・`READABILITY_RULES` の本文は変えない。
- `content/posts/` は触らない。既存の記事は直さない（今後の生成だけが対象）。

## 元に戻す方法

この PR を revert する。データの移行はない（禁止表現の 1 件は revert で消える）。
