# 条番号を本文に書きすぎる問題を直す

## 背景

記事本文に法令の条番号が括弧書きで頻繁に入り、一般読者向けの文章として重くなっている。

```
届出先は、死亡地・届出人の住所地・本籍地のいずれかの市区町村窓口です。届書には死亡の
年月日時分および場所などを記載し、死亡診断書または検案書を添付します（戸籍法第86条第2項）。

死亡届と同時に、市区町村から火葬許可証が発行されます（墓地、埋葬等に関する法律第5条）。
```

読者（個人事業主・相続の相談者）は条文を参照しない。手続きの事実に条番号を添えても、文が重くなるだけで判断の役に立たない。

## 実測（記事265本）

| | 件数 |
|---|---|
| 括弧つきで条番号を引いている記事 | **60本（23%）** |
| 括弧つきの引用の総数 | **94件** |
| 地の文で条番号を引いている記事 | 24本 |

1記事に9件入っているものもあり、**同じ条文を表記を変えて二度引く**事故も起きている。

```
2026-09-08-shitsugi-shotoku-05-30.md（9件）
  （租税特別措置法第40条） （租税特別措置法第40条第19項） （措法第40条） （措法第40条を使わない場合）
```

「租税特別措置法」と「措法」が混在していて、読者にはただの雑音になっている。

## いちばん大事な区別

**「条文を渡すこと」と「条番号を書くこと」は別の話で、今回変えるのは後者だけ。**

| | 内容 | この作業での扱い |
|---|---|---|
| 条文を**渡す** | e-Gov の条文原文をプロンプトに添付する（`law-sources.js`） | **絶対に変えない** |
| 条番号を**書く** | 本文に（○○法第N条）と印字する | **減らす（今回の対象）** |

条文原文の添付は、要件の書き間違いを防ぐための仕組み。実際に 2026-09-14 の貸付農地の記事で、条文が渡らないまま要件を書いて条文上の除外を落とす事故が起きている。`law-sources.js:380` の

```
═══ 法令の原文（条文はこれだけを根拠にする。ここに無い条番号を書かない）═══
```

は**捏造防止のガード**であって、「条番号を書け」という指示ではない。ここには一切触らないこと。

## 既にある前例（同じ論法のルール）

`scripts/lib/article-prompt-static.js:1127` に、まったく同じ理屈のルールが既にある。**新しいルールはこれに揃えて書く。**

```
【読者が使う数字だけを書く（制度の内訳を持ち込まない）】
金額には「読者が判断に使う結論の数字」と「その数字がどう組み立てられているか」の
2つがある。記事に書くのは前者だけ。
  ❌「104万円（基礎控除62万円＋令和8年・令和9年の特例加算42万円）」
  ✓「令和8年分の基礎控除は104万円です」
制度の内訳・区分の境目・改正の建て付けは、あなたが正しい数字を選ぶための材料であって、
読者が使う情報ではない。括弧書きで足すと文が重くなり、読者は結局どの数字を
見ればいいのか分からなくなる。
```

条番号もこれと同じ性質で、「あなたが正しく書くための材料」であって読者が使う情報ではない。

## 決まっている方針

**原則は書かない。ただし例外を認める（「一切書かない」には振り切らない）。**

ユーザーの判断で「例外あり」を選んでいる。条番号が読者の役に立つ場面は実際にあるため。

| | 例 | 扱い |
|---|---|---|
| ❌ 手続きの事実 | 届出先、火葬許可証の発行、添付書類 | 書かない |
| ❌ 制度の建て付け | 課税の根拠条文、特例の条番号 | 書かない |
| ✓ 読者が第三者に根拠を示す場面 | 相続放棄の3か月（民法第915条） | 書いてよい |

## 作業の単位

1本だけ: `01-rule.md`

## 守ってほしい前提

- **`scripts/lib/law-sources.js` には触らない。** 条文原文の添付は維持する
- **既存記事（`content/posts/`）は変更しない。** 公開済みの内容を後から書き換えない方針
- **記事の自動公開・自動マージに関わる変更はしない**
- `assets/js/tax-simulator-boot.js` をコミットに含めない
