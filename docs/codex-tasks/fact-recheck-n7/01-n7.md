# 01 誤りの文を含む文が全部裏付けありのときだけ、止める行を消す（N7・N8）

背景・方針・安全の条件 N-S1〜N-S6 は `README.md`。行番号は main 3dbcd179 の `scripts/lib/fact-check.js`。

## 言葉の決まり（この指示書の中だけ）

- **含む文**: ある置き換え（または本文）を文に分けたもののうち、`normalizedClaim(その文)` が `normalizedClaim(元の誤りの文)` を含む文。
  - 文に分けるのは、今のコードと同じく `splitUnits` の見出しでない単位（`sentenceRows` と同じ分け方）。
  - `normalizedClaim(元の誤りの文)` が空文字なら、含む文は無いとみなす。
- **その文の行**: 再照合の行のうち、`normalizedClaim(行.sentence)` が `normalizedClaim(その文)` と**等しい**もの。
- **全部裏付けあり**: 含む文の 1 つ 1 つについて、その文の行が 1 つ以上あり、その行が全部 `status === '裏付けあり'`。含む文が 1 つも無ければ「全部裏付けあり」とみなす（＝今と同じ）。
