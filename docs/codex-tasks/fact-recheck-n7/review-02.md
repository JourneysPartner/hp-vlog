## 3. 新しい指摘

### 新 L3（Low・理屈の上だけ）元の文が句点だけのとき、R7 で止めない側に倒れる

- **場所**: `fact-check.js:1107-1109`（`containmentNeedle`）、`:1116`、`:1867`。
- **何が起きるか**: 元の文を正規化した結果が「。」だけのとき、句点を外すと空文字になります。
  - 1 回目と 2 回目の「直った」の計算では、369a4083 で効いていた確かめが効かなくなります。

- **直し方**（任意・1 行）: `const n = normalizedClaim(sentence); return n.replace(/[。．.]$/, '') || n;`。指示書の「外した後が空文字なら含む文は無い」とは違う扱いになるので、直さない場合は記録だけで足ります。
