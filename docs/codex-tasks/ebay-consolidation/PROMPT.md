## 進め方

- 作業ブランチは現在チェックアウト済みの `seo/ebay-consolidate` です。ブランチを切り替えないでください。
- **コミットはしないでください。** この環境は隔離されていて `.git` に書けません。変更は作業ツリーに残してください（コミットは別の担当が行います）。
- 指示書の R 番号の順に満たし、最後にテストを流してください。
- 迷ったら指示書の「変更してはいけないもの」と「厳守事項」を優先し、判断が必要な点は実装せずに最終報告に【要判断】として書いてください。
- ネットワークは使えません。`npm install` は済んでいます。
- Git Bash が落ちる場合は PowerShell か cmd を使ってください。
- 記事ファイルは CRLF の場合があります。改行コードは元のファイルに合わせてください（LF と CRLF を混ぜない）。
- push と PR 作成はしないでください。

## 厳守

- `content/posts/*.md` は `01-merge-four-pairs.md` で名指しした 8 ファイル以外、触らない。
- 税務の文章を新しく書かない。移す本文は原文のまま（見出しの階層を 1 段下げるだけ）。数字を変えない。
- 既存 URL を変えない。消える URL は 301 を残す。
- 鍵・トークンをログやファイルに出さない。
- 説明・コメント・最終報告は日本語。

## 完了時に実行して結果を報告するもの

```
npm run build
npm run validate
node scripts/lib/__tests__/test-consolidation.js
npm run masters:test
git status --short
```

（隔離内では子プロセスの起動が EPERM で失敗するテストがあります。その場合は失敗したテスト名とエラーをそのまま書いてください。）
