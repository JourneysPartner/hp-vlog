# 実装指示書: トップページの看板差し替えと「対応地域」ページ（段階4）【段階2・3の後に着手】

作成: 2026-09-03（設計・文章: Claude ／ 実装: Codex）
前提: `README.md`、段階2（サービスページ）・段階3（業種ハブ）がマージ済み。

## 背景と目的

トップページが「eBay輸出専門」一色で、記事の93%を占める他の業種と噛み合っていない。
決定事項に従い、「ネット販売・個人事業主・相続に強い、国税局出身の税理士」を傘にして、
eBay輸出を筆頭の得意分野として残す。住所は出さず「対応地域」ページで受ける。

## 変更してはいけないもの（厳守）

`README.md` に同じ。トップページの**構造（節の順序・クラス）は維持**し、文章と一部の項目だけを差し替える。
実績カウンタの数値（200+／47都道府県／50+）は変えない。

### R2. 「対応地域」ページ `/area/`

`templates/pages/area.html` を新設（段階2の R1 で「ディレクトリ出力」に含める）。

- title H1: **対応地域（全国オンライン対応）**
- description: 毛利順活税理士事務所は全国47都道府県にオンラインで対応しています。Zoom・メール・チャットで相談から申告まで完結。来所不要で、遠方の方や地元に専門の税理士がいない方もご利用いただけます。
- リード: 相談から契約、資料の共有、申告まで、すべてオンラインで完結します。事務所に来ていただく必要はありません。47都道府県、どこにお住まいでも同じサービスをご利用いただけます。
- 「オンラインでできること」（箇条書き）: 初回相談（Zoom）／契約（電子契約）／資料の共有（クラウド・スマホ撮影）／打ち合わせ（Zoom・チャット）／申告・提出（電子申告）／納税のご案内
- 「こんな方にご利用いただいています」: ネット販売・クリエイターなど場所を選ばない事業をしている方／地元に業種を理解する税理士が見つからない方／遠方の親の相続で、現地に行く回数を減らしたい方／来所の時間が取れない方
- 「オンラインで進める流れ」（`flow-step` 4段）: お問い合わせ → 無料相談（Zoom） → ご契約と資料共有 → 記帳・申告
- FAQ:
  - Q: 対面での相談はできますか？ A: 原則オンラインですが、ご事情がある場合はご相談ください。
  - Q: 郵送が必要な書類はありますか？ A: ほとんどの書類はデータで完結します。原本が必要な場合のみ郵送をお願いすることがあります。
  - Q: 税務調査の立会いも遠方で対応できますか？ A: 調査の形式によります。オンライン立会いや、事前準備のみのご依頼にも対応します。
- 構造化データ: `Organization` の `areaServed` に47都道府県を `AdministrativeArea` の配列で出す
  （名称は日本語の都道府県名。住所は出さない）。
- 事務所紹介ページの「対応エリア: 全国（オンライン対応）」の行に `/area/` へのリンクを足す。
- **書かないこと**: 「〇〇県のお客様が多い」「〇〇市の方からのご相談」のような実績を示す記述は、
  事実の裏付けが無いので書かない（【要確認】に相当）。
