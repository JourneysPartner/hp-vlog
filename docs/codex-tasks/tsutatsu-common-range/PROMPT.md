## 要点

`scripts/lib/tsutatsu-parser.js` の `PROVISION_NO_RE` が `～` を許していないため、
`181～223共-6` のような条番号が `looksLikeProvisionNo` で弾かれ、`parseTsutatsuPage` が
その `<h2>` ブロックごと捨てています。ページは取得できているので、落ちているのは解析だけです。

対象は所得税基本通達の4ページ・38件（うち6件は既に取れているので純増32件）。
消費税・法人税・相続税にこの形式はありません。実測済みです。

やることは4つ。

- **A** `PROVISION_NO_RE` に範囲表記を許す（`共?` は範囲の外側）
- **B** `normalizeProvisionNo` で波記号 `〜`(U+301C) `~`(U+007E) を `～`(U+FF5E) に寄せる
- **C** `parseTsutatsuPage` が捨てたブロックを `skipped` で返し、クローラが警告を出す
- **D** `findProvision` の照合順序を「全通達で完全一致 → 無ければ左端」に直す

**範囲を展開しないでください。** `181～223共-6` は1つの条番号であって、条の範囲ではありません。
`181-6` や `223-6` を作らないこと。
