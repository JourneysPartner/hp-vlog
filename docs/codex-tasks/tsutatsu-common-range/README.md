# 共通関係の通達をカタログに取り込む

## 何が起きているか

所得税基本通達には「法第181条から第223条まで（源泉徴収）共通関係」のように、
**複数の条にまたがる共通の通達**を集めた節がある。その条番号は `181～223共－6` と書かれる。

このかたちの条番号を、クローラが**1件も取り込めていない**。
`scripts/lib/tsutatsu-parser.js` の `PROVISION_NO_RE` が `～` を許していないため、
`looksLikeProvisionNo` が false を返し、`parseTsutatsuPage` が
`if (!looksLikeProvisionNo(no)) continue;` でその `<h2>` ブロックごと捨てている。

ページ自体は取得できている。目次からリンクされており、クローラは訪問している。
落ちているのは解析の段階だけ。

## 影響

質疑応答事例の「関係法令」欄からこの通達が引かれているのに、カタログに無いため
原文を渡せない。PR #605 で通達の橋渡しを入れたが、この8件だけは未解決のままになっている。

| 引用 | 出典 |
|---|---|
| 所基通 181～223共-1（支払の意義） | 2件 |
| 所基通 181～223共-4 | 1件 |
| 所基通 181～223共-6 | 1件 |
| 所基通 183～193共-1 | 2件 |
| 所基通 23～35共-2 / -6 / -9 | 3件 |
| 所基通 194～198共-1 | 1件 |

さらに #605 のレビューで、カタログに無いこの番号を**近い番号の別の通達に読み替える**
実装が入りかけた（`181～223共-6` → `181-6` 質権を設定した株式の配当等）。
取り込めていればそもそも起きなかった問題でもある。

## 取り込める見込み（実測済み）

対象は**所得税基本通達の4ページだけ**。他の3通達（消費税・法人税・相続税）にこの形式は無い。

| ページ | h2 | 現状 | 正規表現を緩めた場合 |
|---|---:|---:|---:|
| [法第23条から第35条まで（各種所得）共通関係](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/04/10.htm) | 16 | 0 | 16 |
| [法第181条から第223条まで（源泉徴収）共通関係](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/28/01.htm) | 6 | 0 | 6 |
| [法第183条から第193条まで（源泉徴収義務及び徴収税額並びに年末調整）共通関係](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/30/01.htm) | 7 | 0 | 7 |
| [法第194条から第198条まで（給与所得者の源泉徴収に関する申告）共通関係](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/33/01.htm) | 9 | 6 | 9 |
| **合計** | **38** | **6** | **38** |

現状の6件は4ページ目にある `194・195-1`〜`-6`（併記形。範囲形ではない）で、
これは今も取り込めている。純増は **32件**。所基通は 1,202条 → 1,234条 になる。

## ページの構造

他の節と同じで、特別な処理は要らない。

```html
<h2>（支払の意義）</h2>
<p class="indent1"><strong>181～223共－1 </strong>法第4編《源泉徴収》に規定する…</p>
```

- 条番号は `<strong>` 1つに収まっている（所得税の `37`/`－13` のような分割はしない）
- 波記号は **U+FF5E（全角チルダ `～`）** のみ。4ページ38件すべて。U+301C `〜` は出てこない
- ハイフンは全角 `－`（既存の `DASHES` で半角化される）

## やること

1. `PROVISION_NO_RE` に範囲表記を許す（[01-parser.md](01-parser.md)）
2. 波記号の表記ゆれを `normalizeProvisionNo` で1つに寄せる（同上）
3. 取りこぼしを次から気づけるようにする（同上）
4. テスト（[02-tests.md](02-tests.md)）

カタログの再生成（クローラの実行）は Claude 側でやる。Codex は解析の修正までで止めること。

## やってはいけないこと

- **範囲を展開しない。** `181～223共-6` から `181-6` や `223-6` を作らない。これは1つの条番号であって、
  条の範囲ではない。近い番号の別の通達に寄せるのは #605 で明確に禁止した
- `data/nta-tsutatsu/` を手で編集しない。カタログはクローラの出力だけで作る
- 記事ファイル・公開フロー・承認フローに触らない
