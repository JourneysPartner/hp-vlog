# 照合が正しい文をぼかさないようにする（合計の金額・同じ文の資料の番号）

2026-10-27 の #644（贈与税の非課税制度）の 2 回目の再生成（run 40486086412）で、照合の自動修正が**正しい文を 2 つ**「具体を外す」修正でぼかした（記録の要約「修正 2（具体を外した 2）」）。毛利了承済み（2026-10-27 の引き継ぎ 2）。

## 何が起きたか（記録 `fixtures/644-record-36b726eb.json` で確認済み）

| 主張 | 元の文 | 照合の結果 | 自動修正の後 |
|---|---|---|---|
| c16（金額） | 暦年課税の基礎控除110万円と合わせて使えば、合計2,110万円まで非課税での贈与が可能です。 | Opus は **No.4452 で裏付けあり**と答えた（引用「基礎控除額110万円のほかに最高2,000万円まで控除（配偶者控除）できる」）。機械の確認が「引用が短い・数字が引用の近くに無い」で却下 → 資料なし | 暦年課税の基礎控除110万円との併用については、詳しくは国税庁のタックスアンサーで確認してください。 |
| c35（番号） | …資金を贈与された場合に適用できる制度です（国税庁タックスアンサー No.4508）。 | Opus は資料なし。**同じ文の要件の主張 c45 は No.4508 で裏付けあり** | 番号の「（国税庁タックスアンサー No.4508）」を消した |

原因（引き継ぎのメモの「資料候補に No.4452 が入らなかった」は誤り。4452 は c16 の候補に入っていた）:

1. **c16**: 2,110 万円は資料の 110 万円と 2,000 万円の**合計**で、資料にそのまま書かれた数ではない。数字の確認（`sufficientQuote` → `quoteSupportsNumbers`）は、主張の数が引用の前後 300 字にそのまま無いと却下する。却下された数字の主張は「資料なし」になり、数字の資料なしは承認を止めるので（2026-10-12 毛利決定「案 2」）、自動修正が数字を外して「国税庁で確認」に置き換えた。Claude の再現: 同じ引用・同じ資料で、主張の数を「最高2,000万円」にすると `sufficientQuote` は通り、「合計2,110万円」だと落ちる。
2. **c35**: タックスアンサーの本文には自分の番号（4508）が書かれていない。Opus は番号の根拠になる文を本文に見つけられず資料なしと答えた。同じ文の内容は No.4508 で裏付けられている。

## 方針

- 案 2（数字の資料なしは止めて置き換える）は**変えない**。直すのは、正しいものを「資料なし」と判定してしまう 2 つの型だけ（照合を弱めない。どちらも機械で確かめられる条件に限る）。
  1. 金額の主張の数が、引用の近くの**2 つの金額の合計**で、文に「合計」「合わせて」などの語があり、足す数の片方が文にも書かれている → 裏付けありにする。
  2. 番号の主張で、文が引くタックスアンサーの番号が、**同じ文の別の主張（裏付けあり）の根拠の資料の番号**と一致する → 裏付けありにする。
- 承認画面の「資料が無く案内に変えた箇所」に、AI の答えと機械が却下した理由を出す（今は「前・後」だけで、正しい文が消えたのか分からない）。
