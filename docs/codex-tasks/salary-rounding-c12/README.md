# 給与所得の 1円未満の丸めの誤りを直す（台帳 C-12）

## 背景

給与収入が 660万円以上 850万円未満で 10円単位でないとき、税務シミュレーターの給与所得が 1円多く出る。

- 今のエンジン（`src/tax-engine/income/salary-income.js`）は、660万円以上で給与所得控除額の算式表（`salary_income_deduction_table`）を引き、**控除額を 1円未満切り捨ててから**収入から差し引く。
  - 例: 収入 8,499,999円 → 控除額 1,949,999.9円 → 1,949,999円 → 給与所得 6,550,000円
- 正しくは、**給与所得の金額を計算してから 1円未満を切り捨てる**（→ 6,549,999円）。根拠（2026-10-28 に原本で確認）:
  1. 国税庁「令和7年分 年末調整のしかた」の「電子計算機等による年末調整」（9頁）: 算式表「6,600,000〜8,499,999｜A×90%−1,100,000円」と「（注）2 年調給与額が660万円以上のものについて、上記の算式により計算した金額に1円未満の端数があるときは、その端数を切り捨てた額を給与所得控除後の給与等の金額とします。」
  2. 所得税法 別表第五の備考（給与等の金額が 6,600,000円以上の居住者の給与所得控除後の給与等の金額の 1円未満の端数は切り捨てる）
  3. 「令和7年分 確定申告の手引き」給与所得金額の計算表: 「6,600,000円〜8,499,999円｜A×0.9−1,100,000円」で給与所得を直接求める
  - 給与所得控除額を先に切り捨てる根拠になる一次資料は見つからない。
- 影響: 1円の差で、合計所得金額が基礎控除の段の境目（489万円）を越えることがある。
  - 給与 6,655,556円（ほかの所得・控除なし）、令和7年分の所得税＋復興特別所得税: 正 423,200円／今 433,400円
  - **今公開中の令和7年分の結果にも及ぶ。** 住民税も同じ関数を使う。
- 詳細: `docs/tax-simulator/deferred-items.md` の C-12。

## 方針

- マスター（`data/tax-simulator/masters/`）は変えない。算式表の記録の `rounding_rule_id`（`R-TRUNC-1-YEN`）は、**控除額ではなく給与所得に当てる**。
- 直すのはエンジンの給与所得の計算 1 か所と、試験。
- 公開中の画面に効かせるため、公開用のまとめファイル（`assets/js/tax-simulator.<8桁>.js`・`tax-simulator-manifest.json`）を作り直してコミットする。2026-09-03 のまとめファイルの後に入った変更は、段 1（PR #721）のマスターの控え（`source_hash`・`as_of_date`・`verified_at`、値は不変）だけで、`src/` の変更は無い（2026-10-28 確認）。
