# 国税庁 Q&A の取り込みで問の区切りを見失わないようにする（2026-11-14）

## 背景
- 毎月 10 日の自動実行（`.github/workflows/refresh-nta-qa.yml`）が、国税庁の Q&A・事例集（`data/nta-qa/`）を取り直して PR を作る。
- 2026-11-10 の PR #761 は、国税庁の資料そのものはほとんど変わっていない（実質の変更は教育資金の冊子の「制度の詳細へ」6 字だけ）のに、383 ファイルが変わった。
- 原因は PDF から文字を取り出す部品の違い。今の main のデータは 2026-09-01〜09-15 にこの PC の **xpdf 4.00**（Glyph & Cog）で取り込んだもの。GitHub の自動実行は ubuntu の **poppler**（`poppler-utils` の `pdftotext`）で、文字の並び順が違う。
- その結果、次の 2 つが起きた。
  1. **軽減税率 Q&A の問の区切りを見失った**（138 問 → 114 問、24 問が前の問にくっついた）。poppler では、左の余白にある「問100」の札が、問の 1 行目の後ろに出る:
     `（ホテルに対して販売する新聞） 当社は、新聞販売店を経営しています。当社がホテルに販売する週２回以上発行される 問100 新聞は、…`
     今の区切り（`scripts/crawl-nta-qa.js` の `splitByQuestion`）は「（見出し）」の直後に「問N」がある形しか拾わないので、問100 の本文が問99 の中に入る。
  2. **表や図の文字の並び順だけが変わった**（約 120 ファイル）。良くなった所（例: invoice/113 で経過措置の期間と「80％」「70％」が並ぶ）と悪くなった所（例: invoice/04・24-4 で表の文字が混ざる）がある。中身の文字は同じで、順番だけ違う。
- 照合（公開前の事実確認）は 11/9 から Q&A を問ごとに使う（`scripts/lib/fact-evidence.js` の Q&A 専用 1 枠、PR #757）。問がくっつくと、題名と本文が食い違い、照合の質が落ちる。

## 方針（利用者の決定 2026-11-14:「今の仕組み（照合など）の質を落とさないように、区切りを直してから取り直す」）
1. poppler の並び（問番号が 1 行目の後ろに来る形）でも問を区切る。本文は今の main と同じ形（「（見出し） 問N 本文…」）に整える。
2. 文字の中身が同じで並び順だけ変わった場合は、今の本文を残す（書き換えない）。本物の改訂（文字が増えた・減った・変わった）は今までどおり取り込む。
3. 区切った結果、今あるはずの問が 1 つでも見つからない資料は、その資料を更新せず、消しもしない。理由を PR 本文と実行の記録に出す。

## 国税庁が問を本当に削った・番号を振り直したとき（手で直す手順）
- 問が欠けた資料は更新しない（R3）ので、国税庁が本当に問を削ったり番号を振り直したりすると、その資料は毎月「区切りを見失った問があるため … は更新していません」と出て、その後の改訂も取り込まれない。
- 国税庁の資料で削除・振り直しを確かめたら、消えた問のファイル（`data/nta-qa/<source_key>/<doc.id>-<問番号>.json`）と `index.json` のその行を手で消す PR を作ってマージし、`refresh-nta-qa.yml` を手動で動かして取り直す。
