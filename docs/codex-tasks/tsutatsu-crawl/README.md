## 背景

事実照合（#672、2026-10-15 マージ）の「マージ直後の手順」で Crawl NTA Tsutatsu（run 38700904221）を実行したところ、9 種類の通達すべてが「取り込みが完了していないため既存のカタログを保持します」で終わり、新しい通達（財産評価基本通達・措置法関係通達 4 種）は 1 件も入らず、既存の 4 基本通達も更新されなかった。

| 分類 | ページ | 原因 | 直し方 |
|---|---|---|---|

## 方針

- 読める項目を読む（A・B・E）。
- 項目の無いページ（C・D）とリンク切れ（F）は、通達のカタログに `non_provision_pages`・`missing_pages` として URL と理由を残し、取り込みは続ける。
- **安全側は残す**: 次のどれかなら、今と同じくその通達を取り込まない（既存を保持）。
  - 番号らしい書式（`<strong>`・`<span class="bold">`・`<b>` の中身が通達番号の形）があるのに 0 件のページが 1 つでもある（本当の読み落とし）。
  - リンク切れが、その通達の節ページの 3% を超える、または 10 ページを超える（サイトの構造が変わった疑い）。
  - 取得の失敗（リンク切れ以外の HTTP エラー・時間切れ）が 1 つでもある。
- 「項目の無いページ」の判定は、URL が附則・別紙・前文（`fusoku`・`bessi`・`zenbun`）か、番号らしい書式が 1 つも無いページ。附則の「1」「2」のような番号は通達番号として取り込まない（照合で使わないため）。
