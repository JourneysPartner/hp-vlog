# 照合が表の数字を読み違えて正しい数字を消す不具合を直す（fact-table-numbers）

2026-10-26 毛利さん了承（「全て進めて」）。照合（Opus）の答えはそのままに、**機械の確かめが数字を読み違えて正しい裏付けを落とす**不具合と、それに続く表の行の扱いの穴を直す。

## 背景（10/26 の日次 #704「小規模宅地等の特例は誰が使える？」）

- 記事の表「| 特定事業用宅地等 | 400㎡ | 80% |」など 4 行に対し、Opus は国税庁タックスアンサー No.4124 の表を引用して 6 件とも「裏付けあり」と正しく答えた。
- ところが機械の確かめ（`sufficientQuote` → `quoteSupportsNumbers`）が「引用が短い・数字が引用の近くに無い」で 6 件とも落とした。**原因: 国税庁のページの表は列が空白で区切られている（「400 80％」「200 50％」「330 80％」）。`normalizedQuote` が空白を全部消してから `normalizedNumbers` が読むので「40080％」「20050％」「33080％」という 1 つの数になる。**
- 落ちた主張は資料なし → 具体を外す修正で、表 4 行の面積・割合の列が全部「国税庁の案内で確認」に、「よくある間違い」と「まとめ」の文から 80%・50% が消えた（記事は Claude が手で元に戻した: 下書きの枝 90feffe9）。
- 面積の列まで消えた理由: 抜き出しが返した「限度面積は400㎡」（要件）が、列名「限度面積」が表の見出しの行にしか無いため、データの行と語が一致せず「本文に見つからない」で捨てられ、照合されなかった。そのため具体を外す修正の「残す数字」（keep）が空で、80% と一緒に 400㎡ も消えた。

## 測った数字（AI なし、基準は `%TEMP%\hpstatus\fact-table\`）

- 照合の資料（国税庁・法令・通達のカタログ 13,273 件）のうち **419 件・1,261 か所**で、空白をはさんで数字が並ぶ（算用数字どうし 661・漢数字どうし 211・混在 389）。見本はどれも 1 つの数として読むのが誤り（「2 1以外の者」→21、「一 二千五百万円」→一二千五百万円、表の「400 80％」→40080％ など）。区切って読むと読み取る数字が変わる資料は 303 件。
- 今は資料全体に読めない数があると、その資料を使う数字の主張は全部落ちる（`sufficientQuote` の「`normalizedNumbers(text).includes(null)`」）。そうなっている資料は 3 件（通達 法基通9-1-6の8・評基通24-7・所基通36・37共-7の2 の表）で、区切って読むと 0 件になる。
- 保存してある照合の記録 267 件では、この不具合で落ちた答えは 8 件（うち 6 件が 10/26）。まれだが、表が中心の記事では致命的。
- 採らない案: 「数字は引用そのものの中だけで確かめる」。今の裏付けありの数字の主張 2,095 件のうち 180 件（表の行では 431 件中 42 件）が新たに落ち、多くは正しい（「年110万円」の「1」、「令和8年分」と「令和8年9月30日」など）。前後 300 字の範囲で確かめる今の決まりは変えない。

## 厳守

- 照合の判定・候補（7 件）・資料表・抜き出しと判定の指示文・Batch の使い方は変えない（R3 の修正の指示文に 1 文足すのだけ例外）。
- 引用の位置の探し方（空白を無視して原文の中の引用を探す）と、数字を確かめる範囲（原文の引用の位置の前後 300 字、範囲の端で切れた数は採らない）は変えない。
- 区切りなしでつながった漢数字（法令の表で「百分の十二百万円」のように空白も無いもの）は今回の対象外（別作業）。
