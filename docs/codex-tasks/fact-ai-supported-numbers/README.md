# 照合の AI が「裏付けあり」と答えた文を、機械の数字の確かめだけで書き換えない

2026-11-06 の利用者決定（案 A）。2026-10-28 の決定「AI が裏付けありと答えたのに機械の数字の確認で落ちた数字は、件数を数えてから扱いを決める」の結論。

## 何が起きていたか

- 照合の判定（`fact-check.js` の判定の確かめ、939 行付近）は、AI の答えの引用が資料にあっても、文の中の数字が引用の近くにそのまま無ければ「引用が短い・数字が引用の近くに無い」で却下し、状態を「資料なし」にする。
- 数字の主張の「資料なし」は、2026-10-12 の決定（案 2）で本文を書き換える対象になる（`blockingFinding`）。書き換えられないと残って `revise` になる。
- このため、計算の答え（売上 1,000 万円 → 売上税額 100 万円 × 3 割 = 30 万円）や、資料に字が無い年度（「令和8年度税制改正」）を含む正しい文が、ぼかされるか承認を止めていた。
  - #693（一人親方のインボイス）: 機械が却下した 4 文すべてで、AI は「裏付けあり」と答え、No.6498（3割特例）・No.6505（みなし仕入率）を正しく引いていた。2 文は書き換えられず `revise`、2 文は正しい数字が消された。
  - #690: 「110万円を超えた場合…」の文も同じ（AI は裏付けあり）。

## 決定（2026-11-06 利用者）

照合の AI が「裏付けあり」と答え、引用は資料にあるのに、機械の数字の確かめだけで落ちた文は、本文を書き換えず、承認も止めず、「人が確かめる箇所」に出す。

## 安全の決まり

- **T1 引用が資料にあるものだけ。** 対象は却下の理由が「引用が短い・数字が引用の近くに無い」のものだけ。この理由は、資料の番号が読める・候補の資料である・引用が資料にある（`quoteExists`）を通った後でしか付かない。「引用が資料に無い」「資料の番号が読めない」など、ほかの理由で落ちたものは今のまま。
- **T2 AI が「裏付けあり」と答えたものだけ。** AI が「食い違い」「期限の書き漏れ」と答えて落ちたもの（#744 の「40万円未満」など）は今のまま。
- **T3 書き手の文だけ。** 照合の自動修正で置き換えた文（再照合の段階）は今のまま（fact-check-override の S6 と同じ考え方）。
- **T4 人に必ず見せる。** 数字を機械で確かめられていないので、照合の要点の欄（折りたたまない場所）に件数と文と AI の引用を出す。

## 受け入れたこと（弱くなる点）

- AI が誤って「裏付けあり」と答え、文の数字が資料と違う場合（例: 資料は 1,000 万円、記事は 2,000 万円）、これまでは本文が書き換わるか止まったが、今後は本文のまま「人が確かめる箇所」に出るだけになる。T4 で人が必ず目にする場所に出して補う。

## 元に戻す方法

この PR を戻す。`LOGIC_VERSION` を上げるので、戻すと次の照合から元の扱いに戻る。
