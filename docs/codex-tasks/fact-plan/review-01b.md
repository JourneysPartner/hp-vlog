## 直すもの（01c）

### G1（M1）引けない id で注意書きを増やさない

1. 差し戻し・更新案で新しく足す資料の id は、`resolveMaterial` で引けるものだけを `fact_materials` に足す（引けない id は黙って捨て、記録しない）。範囲の表記（`37-5～37-6` など）から id を作らない。
2. 「引けない ○ 件」の注意書きは、**記録済みの** `fact_materials` のうち引けないものだけで数える。
3. 計画の項目（`fact_plan_status`）がある記事では、`inheritFactMetadata` の注意書きの比べ方を ` / ` で区切った部分ごとにし、既にある部分は足さない。「計画:」で始まる注意書きは新しい差し止め（`fact_check_prev_recommendation` を revise にする理由）とみなさない。**計画の項目が無い記事の動きは変えない**（P8）。
4. 試験: `fact_materials: "ta:4452;ta:0000"`（1 件引けない）で、照合 revise（変更前の推奨 publish）→ 部分修正の差し戻し 2 回 → 照合 ok。注意書きの数が増えず、`fact_check_prev_recommendation` は publish のまま、最後に `recommendation` が publish に戻る。本文に `所基通37-5～37-6` のような範囲の引用がある記事の差し戻しで、`fact_materials` に引けない id が足されない。

### G2（M2）資料探しの税目の決め方

除外の規則を次に置き換える（2026-10-20 に本物のカタログで 17 例を試算し、すべて妥当だった）。

- **ページの税目**: 今の `evidenceTax`（タックスアンサー・質疑応答は URL の分類、法令は法令名、通達は通達名）。Q&A は `tax_category_code`。**租税特別措置法など法令名で税目が決まらない条は、題名の語で決める**: 「必要経費」「所得税」「譲渡所得」「事業所得」→ 所得税、「損金」「益金」「法人」→ 法人税、「贈与」「相続」→ 相続税（贈与税を含む）、「消費税」「仕入税額」→ 消費税。どれにも当たらなければ税目なし。
- **制度の税目**（次の順で最初に決まったもの）:
  1. 制度名に税目名そのもの（所得税・法人税・消費税・インボイス・適格請求書・相続税・贈与税）があれば、その税目（「相続」「会社」のような一部の語では決めない）。
  2. 記事の税目（`tax_domain` から決まる 1 つ）のページで、題名が当たる**タックスアンサー・Q&A・法令**があれば、記事の税目。
  3. 題名が当たるタックスアンサー・Q&A のうち検索の点が最も高いページの税目。
  4. 記事の税目。
  5. どれでも決まらなければ絞らない。
  （質疑応答は税目をまたぐ細かい事例が多いので、制度の税目を決めるのに使わない）
- **絞り込みと並べ方**: 税目が分かっていて制度の税目と違うページは外す。税目なしのページは残す。並べ方は「制度の税目のページ → 題名が当たる → 種類（タックスアンサー → Q&A → 質疑応答 → 法令・通達）→ 検索の点 → 本文の出現回数」。
