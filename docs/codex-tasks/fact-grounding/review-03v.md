#### 2. 新しい指摘

**指摘 1 — Medium：修正の歯止めが、年だけの日付を完全一致で比べている**

場所は `fact-check.js:859-863`（`keepNumbers`・`removeNumbers` の `originalNumbers.includes(n)`）です。要約の「日付:令和6」と、本文の「日付:令和6-1-1」が一致しないため、次の 2 つが起きます。

- **(a) 正しい日付を守らない（03v で新しくできた道）**
  - V3 で、年だけの適用年の主張（「令和6年以降の贈与に適用」）が「裏付けあり」になり、`keep` に入るようになりました。
  - ところが、歯止めがその日付を「残す数字」から落とします。
  - 試した文: 本文「令和6年1月1日以降の贈与からは、年間110万円の基礎控除と300万円の特別控除が新設されました。」で、300万円が「資料なし」。
  - 修正が「令和6年1月1日以降の」ごと消すと、採用されて再照合でも解決になり、**`status: ok` で正しい日付が本文から消えました**。
  - 要約が年月日（「令和6年1月1日以降」）なら、同じ修正は「裏付けのある数字を消しています」で却下されます。
- **(b) 誤った日付を消させない（U2 からある道）**
  - 試した文: 本文「令和7年1月1日以降…年間110万円…」（正しくは令和6年）、要約は「令和7年以降…」。
  - 110万円だけ部分的に裏付けられて残し、`removeNumbers` が空になります。
  - そのため「令和7年1月1日」を残した修正が採用されます。
  - 再照合の要約に日付が無いと **`status: ok`** になりました。日付が有れば `revise` です。要約が年月日なら「資料の無い数字が残っています」で却下されます。
- **直し方:**
  - 年だけの要約の数字を「同じ文の、基準日を除いた、同じ元号・年の年月日」に広げる関数を 1 つ作り、`keepNumbers` と `removeNumbers`（あわせて `supportedNumberForms`、`:388`）で使う。
  - 試験は上の (a)(b) の 2 例。
- どちらも修正役や抜き出し役の LLM が誤ったときに起きる道なので Medium としましたが、指摘 2 と同じ種類の穴です。

**指摘 2 — Low：一覧が、修正で消えた文を残し、同じ主張を 2 回数える**

場所は `fact-check.js:83-88`（`outsideCandidateClaims`）です。

- 1 つの文に、要件の主張（候補の外の資料で裏付けあり）と金額の主張（資料なし）がある場合に起きます。
- 修正で文が書き換わると、元の文の行と再照合の行が別の主張として両方残ります。主張を見分ける鍵に、文そのものが入っているためです。
- 試した結果、要約は「候補の外の資料で裏付け **2 件**」になり、一覧には本文に無い元の文が出ました。
- 今ある `resolved` の除外は、直した主張自身の id しか除きません。その主張は「裏付けあり」でないので、この関数では実質働いていません。
- 直し方: 修正を当てた文（`corrections` のうち `after` が空でないものの `before`）の行は、解決したかどうかに関係なく `claims` から除く。そのうえで試験を足す。

**指摘 3 — Low：要約に基準日を含む主張を、抜き出しで捨てるようになった**

場所は `fact-check.js:355` です。

- 03u の抜き出しは、完全一致の比べ方では基準日を残した文を使い、年だけの比べ方でだけ基準日を除いていました。03t の `sufficientQuote` も同じく、完全一致は基準日を残した文で比べていました。

**指摘 4 — Low：要件・判定・手続 の主張に入った数字は、兄弟制度のページで通る（設計上残した道）**

- 一方、数字を含む 要件・判定・手続 の主張は、数字を確かめずに候補の外の資料で「裏付けあり」になります。
  - 要件「受贈者の合計所得金額が1,000万円以下」は、4511 の（注1）で裏付けありになりました（正しくは 2,000万円）。

- 承認の結果は 03t と同じです（03t でも、止めない「資料なし」で承認できる）。表示は新しい一覧に出ます。

- 実記録では、候補の外の資料で裏付けあり となった 要件・判定・手続 50 行のうち 23 行が数字を含んでいました（ほとんどは 4402 の 110万円で、正しい使い方）。そのため、数字を含むものを一律に止めると、U3 の効果の多くを失います。
