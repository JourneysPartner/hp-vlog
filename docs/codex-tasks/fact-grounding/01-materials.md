# 01 書き手に渡す資料を論点に合わせる

背景は `README.md` の原因 1〜3。新規生成・差し戻し再生成・更新案の 3 経路すべてに効くよう、資料の組み立ては共通の部品で行う。

## R1 補助出典の本文を渡す

- `topic.source_supplements`（論点別選定で選んだ補助出典）の本文を、主出典と同じ形式で出典本文ブロックに入れる。今は題名だけ（`supplementalSourceLabels`）。
- 並び: 主出典 → 補助出典（選定順）→ 既存の参考（`getRefsForTopic` の 1 件）。URL の重複は 1 回だけ。
- 長さの予算: 1 ページあたり既定 6,000 文字、合計既定 24,000 文字（環境変数 `SOURCE_BODY_MAX_CHARS_PER_PAGE`・`SOURCE_BODY_MAX_CHARS_TOTAL`）。ページが長いときは、記事の論点語（`tax_terms`・`source_term`・題名の語）を含む段落を優先して残し、「抜粋」と明記する（今の「冒頭のみ抜粋」より優先）。予算を超えた出典は題名だけにし、ログに出す。
- 図（画像）を渡すのは従来どおり主出典だけ。

## R2 関係法令の連鎖

- 渡す国税庁ページ（主出典・補助出典・参考）それぞれの「根拠法令等」「関係法令」欄に挙がっている法令・施行令・通達の条番号を、カタログ（`data/law-sources/`・`data/nta-tsutatsu/`）で解決できる範囲で原文を添える。通達については既存の `buildTsutatsuBlockFromSourceKankei` がしていることを、法令・施行令にも広げ、補助出典にも広げる。
- 例: 質疑応答事例 相続税 10-05 の関係法令「措法69の4①」→ 措法69の4 の条文（今もある）。TA No.4124 の根拠法令等「措法69の4、措令40の2、措規23の2、措通69の4-27、28、郵政民営化法180」→ 措令40の2 の条文（措置法施行令のカタログは今は一部の条だけで 40の2 は無い。04 で収録範囲を広げた後に解決できるようになる）。項目名はページの種類で違う（タックスアンサーは `sections` の「根拠法令等」、質疑応答事例は「関係法令通達」等）ので、実データで確かめて両方に対応する。カタログに無いもの（措置法関係通達など）は 04 で足す。今は解決できなかった条をログに出すだけ。
- 上限: 条は既定 8 件、合計既定 12,000 文字（`LAW_CHAIN_MAX_ARTICLES`・`LAW_CHAIN_MAX_CHARS`）。項・号の指定があれば、その項を含む条の全文を渡す（括弧書きの読み違いを防ぐため、項だけを切り出さない）。
- 法令ブロックの見出しに、「条文の括弧書き・ただし書きは、その条の主語・対象に限って読むこと。別の場面（例: 建替え中）に当てはめるときは、その場面を定めた通達・施行令が添付されている場合だけにすること」という注意を足す。

## R3 主出典が汎用ページのときの補強

- 「汎用ページ」: 公開済み記事の主出典としての使用回数が多いページ（既定 10 本以上。数は `content/posts` から数える。既定値は環境変数で変更可）、または一覧ファイル `data/generic-source-pages.json`（初期値: TA No.1350・2210・2200・6501・4152・2080・2260・invoice_about の 8 件。理由つき）にあるページ。
- 主出典が汎用ページのとき、出典の由来（curated・explicit を含む）に関係なく `enrichTaxTerms` → 論点別選定を行い、補助出典を最大 3 件足す。**主出典は替えない**（人が決めた対応表の結果を勝手に上書きしない）。
- 論点別選定で何も見つからなかったら、`review_warning` に「主出典が汎用ページで、論点に合う資料が見つからない」と書く（03 の照合で資料なしが増えるはずなので、人の目を向けさせる）。

## R4 生成時のログ

`[source]` のログに、渡した資料の一覧（種類・番号・文字数・抜粋かどうか）、予算で落とした資料、解決できなかった条を出す。下書きの frontmatter に `source_bundle`（渡した資料の URL か条番号を `;` 区切り、最大 20 件）を残す（03 の照合と人のレビューで使う）。

## テスト（`scripts/lib/__tests__/test-materials-bundle.js`）

1. #644 の topic（`source_supplements` に 4510・4511・4405）で、出典本文ブロックに 4 ページの本文が入り、4511 の本文に「令和9年3月31日」が含まれる（実データ）。
2. 予算: 合計予算を小さくすると、後ろの出典が題名だけになり、ログに出る。長いページは論点語を含む段落が残る。
3. 関係法令の連鎖: 質疑応答事例 相続税 10-05 と TA No.4124 を渡すと、措法69の4 の原文が添付され、措令40の2 は「カタログに無い条」としてログに出る（実データ。04 の後は添付される）。項指定があっても条の全文。上限件数が効く。
4. 汎用ページ: 主出典 No.2210 の topic で論点別選定が呼ばれ（偽の関数）、補助出典が足され、主出典は変わらない。何も見つからなければ `review_warning` に記録。
5. 3 経路（新規・差し戻し・更新案）で同じ部品が使われる。

## 変更してはいけないもの

- 主出典の決め方（対応表・明示指定・LLM 選定）、出典ガード（`source_guard_version`・確信度の判定）。
- 出典本文ブロックの既存の【厳守】1〜3・5・6（4 は 02 で変える）。
- 図の扱い。
