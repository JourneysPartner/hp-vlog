# 03d 3 回目のレビュー指摘の修正（2026-10-10、Opus 5.5 xhigh の差分レビュー）

対象はコミット 884804ac（03c）。総合判定「軽微を直せばマージ可」（High 0・Medium 2・Low 2）。前回の指摘は G3（数字の照合）を除いてすべて FIXED。H1〜H4 を直す。変えるのは下に書いた箇所だけ。

## H1（Medium）記事の文の数字が誤っていても、主張の要約が正しければ「裏付けあり」になる

- `scripts/lib/fact-check.js` 111 行付近（`sufficientQuote` / `normalizedNumbers` の使い方）。03c の G3 で、照合する数字を主張の要約（`claim.claim`）だけから取るようにした。抜き出しの LLM が要約を知識で直してしまう（文は「令和8年3月31日」＝誤り、要約は「令和9年」）と、要約の数字 [9,3,31] だけが引用と比べられて通り、文の誤った期限が照合をすり抜ける。
- 直し方（落とす側）:
  - `裏付けあり` の条件に「**要約の数字がすべて文（`sentence`）の数字にも含まれること**」を足す。含まれなければ `資料なし`。
  - 要約に数字が無いときは、文の数字で引用と照合する（今は要約に数字が無いと、正しい文でも必ず資料なしになる）。
  - 文の数字の読み取りは G3 の文脈の規則（「一定」を 1 と読まない）をそのまま使う。
- テスト: 文が令和8年・要約と引用が令和9年 → 資料なし。既存の「過去には令和8年…」のテスト → 裏付けありのまま。要約に数字が無く、文と引用の数字が一致 → 裏付けあり／一致しない → 資料なし。

## H2（Medium）法令の漢数字の割合・分数を読み違え、正しい記述を資料なしにして消す（03b からの退行）

- `fact-check.js` 80〜81 行付近（数の文脈の判定）。「百分の二十」は「百」だけ 100 と読まれ、「二十」は前が「分の」なので読まれない。主張「税率は20%」が資料なしになり、修正で正しい税率が案内文に置き換わる。「2分の1」と「二分の一」も同じ。04 で条文（漢数字）が根拠になりやすくなったので起きやすい。
- 直し方: 前の文脈に「分の」を足す（例 `/(?:令和|平成|昭和|第|分の)$/`）。「百分の二十」は 20%、「二分の一」は 1/2 として、「20%」「2分の1」「50%」と比べられるようにする（割合を比べる形に揃える。揃え方は実装に任せるが、違う割合を同じとみなさないこと）。
- テスト: 「20%」と「百分の二十」→ 裏付けあり。「2分の1」と「二分の一」→ 裏付けあり。「4分の3」と「四分の一」→ 資料なし。「10%」と「百分の二十」→ 資料なし。

## H3（Low）出典の決まり方が弱い下書きを差し戻すと、frontmatter の `tax_terms` と `source_bundle` が空になる

- `scripts/generate-draft.js` 3202〜3212・3221 行付近（`recordMaterialMetadata`、2571 行付近）。domain-fallback・ultimate・unknown の下書きを差し戻すと、このブロックの `topicLike` が `tax_terms` も `source_bundle` も持たないので、空で書き戻す。直後の照合の根拠探しが弱くなり、公開後の一括照合にも空のまま残る。
- 直し方: 新しく決まらなかった項目は元の値を保つ（例 `recordMaterialMetadata(content, { tax_terms: srcMeta.tax_terms, source_bundle: srcMeta.source_bundle, ...topicLike })`）。
- テスト: 弱い出典で主出典が汎用ページでない下書きを差し戻しても、2 つの項目が残る。

## H4（Low）項目 0 件の本文ページを全部ログに出す

- `scripts/crawl-nta-tsutatsu.js` 155 行付近はエラーを先頭 5 件しかログに出さない。G8 で「本文ページが 0 件なら通達ごと失敗」にしたので、前文・附則のような項目の無いページがあると、どのページが原因か分からないまま取り込めない。
- 直し方: 「本文ページの項目が0件です」のページは、件数の上限なしで URL を全部ログに出す。0 件で失敗にする規則は緩めない（正当に項目の無いページは、取り込みのログを見て Claude が除外リストに足す）。
- テスト: 0 件のページが 6 件以上ある偽の取り込みで、全部の URL がログに出る。
