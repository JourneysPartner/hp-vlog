# 中国輸入をネット販売のサービスページと記事の題材に足す（china-import）

## 背景

- 2026-11-14、毛利さんが「中国輸入（アリババ・タオバオなどからの仕入れ）の物販の依頼を受ける。関税・輸入消費税・通関書類の処理を受けられる業務として書いてよい」と回答した。実績の件数は聞いていないので書かない。
- 中国輸入は国内で売るための仕入れなので、受け皿は `/services/online-seller/`（ネット販売・せどり・フリマの税務）にする。eBay 輸出のページ（輸出・還付）には足さない。

## 何を足すか

1. `/services/online-seller/` に、中国輸入の受け方を足す（説明文・こんな方に・できること・対応している業種・よくある質問 2 問）。
2. 取扱業務の一覧（`/services.html`）と、ほかのページのサービスカード（`service-links.js` の説明文）にも「中国輸入」を足す。
3. 記事の題材の候補に中国輸入の論点を足す。足し方は **検索の種語**（`data/search-suggest-seeds.json`）に 5 語を足すこと。

### 題材を種語で足す理由

- 日次の記事の選び方（`scripts/lib/topic-selector.js` の `priorityBreakdown`）は、需要の証拠（検索候補・GSC・質疑応答）を 3 倍で数える。手で並べた題材（`scripts/topic-pool.js`）は需要の証拠を持たないので、ほぼ選ばれない。
- 種語を足すと、週 1 回の取得（月曜 2:00、`update-suggest-topics.yml`）が Google の検索候補を取り、AI が税務の問いだけを候補にして PR を出す。人が検収してマージすると、需要の証拠つきの候補になる。
- 2026-11-14 に Claude が検索候補を確かめた結果（1 語ずつ取得）:

| 種語 | 出た検索候補（抜粋） |
|---|---|
| 中国輸入 関税 | 関税 消費税／いつ払う／いくらから／かからない／計算 |
| 輸入消費税 仕訳 | 税込経理／税抜経理／簡易課税／免税事業者／freee |
| 輸入消費税 控除 | 仕組み／時期／控除対象外消費税 |
| 輸入消費税 免税事業者 | 仕訳／勘定科目／還付 |
| 輸入許可通知書 | 消費税／dhl／fedex／再発行／見方 |

- 「中国輸入 確定申告」「中国輸入 経費」「中国輸入 税金」は検索候補が出なかったので使わない。
- 取得は全部で 50 語になる（試験の上限は 100、指示書 phase3 の目安は約 50）。

## 文面の裏付け（Claude が原文で確認、2026-11-14）

| 文面 | 根拠 |
|---|---|
| 中国にある商品を買う取引そのものには日本の消費税はかからない | 消費税法 4 条 3 項 1 号（譲渡の時の資産の所在場所で国内かを決める） |
| 輸入のときに税関で消費税がかかる | 消費税法 4 条 2 項（保税地域から引き取られる外国貨物に課す） |
| 輸入消費税を差し引くには帳簿と輸入許可通知書などの保存が要る | 消費税法 30 条 1 項・7 項・9 項 5 号 |
| 差し引けるのは課税事業者 | 消費税法 30 条 1 項（免税事業者を除く）、消費税法基本通達 11-1-7 |
| 代行業者の名義で輸入した場合は扱いが変わる | 消費税法基本通達 11-1-6（輸入申告の名義人と実質的な輸入者が違う場合は、限られた条件のときだけ実質的な輸入者が控除する） |
| 国際送料や関税など仕入れのためにかかった費用は仕入原価に含める | 所得税法施行令 103 条 1 項 1 号イ（引取運賃・購入手数料・関税を取得価額に加える） |
| 簡易課税などを選ぶと扱いが変わる | 消費税法 37 条（みなし仕入率で控除額を出す） |

- 法令は `data/law-sources/`（e-Gov、2026-10-01 施行時点）、通達は `data/nta-tsutatsu/shohi.json`（2026-10-17 取得）で確認した。

## 安全の決まり（全段階共通）

- T1 変えてよいファイルは `01-service-page-and-seeds.md` の「変えてよいファイル」の 6 つだけ。
- T2 ページに出す文は、指示書の文を一字一句そのまま使う。言い換え・補足・句読点の変更をしない（税の説明は原文で確かめた文だけを出す）。
- T3 件数・金額・割合・日数などの数字を足さない（事務所について書いてよい事実の範囲を守る）。
- T4 ページの題名（`<title>`）・見出し（`<h1>`）・副題（`page-hero-sub`）・canonical は変えない。
- T5 「ご相談の例（想定）」は 2 件のまま（`test-service-pages-content.js` の決まり）。
- T6 既にある文・FAQ・種語を消したり並べ替えたりしない。置き換えるのは指示書で指定した説明文の 3 か所だけ。
- T7 アイコンは既にスプライトにあるもの（`bi-box-seam`）を使い、`templates/partials/icons.svg` を変えない。

## 受け入れ確認（Claude）

- 差分を読み、T1〜T7 を一つずつ確かめる。ページの文は指示書の文と完全に一致するかを機械で照らす。
- `sbx` を通して、ビルド・関係する試験 5 本・`validate.js` を流す（直す前の main では、すべて通過。validate の警告の行は 124）。
- 生成した `services/online-seller/index.html` で、よくある質問 2 問が FAQ の構造化データ（FAQPage）に入ること、「対応している業種・働き方」に中国輸入が出ることを見る。

## 元に戻す方法

- この PR を revert する。データの移し替えや生成物のコミットは無いので、revert だけで元に戻る。
- 種語から作られた候補（`data/search-suggest-topics.json`）は、週次の PR をマージした後にだけ増える。要らなくなったら、その候補を `data/withdrawn-topics.json` の手順で取り下げる。

## コードの入口

- ページの元: `templates/pages/services/online-seller.html`、`templates/pages/services.html`

- 種語: `data/search-suggest-seeds.json`（`scripts/update-suggest-topics.js`）
