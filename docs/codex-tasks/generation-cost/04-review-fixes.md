# 04 01〜03 のレビュー指摘の修正

`review-01-03.md`（Opus 5.5 xhigh「修正してからマージ」）の High 1・Medium 7 と、一部の Low を直す。行番号はレビュー時点（65733b18）。

## F1（H1）Gateway で本文全体を返す呼び出しが途中で切れても気づけない

- `CONTENT_MODEL_PROVIDER=gateway` のとき、差し戻しの再生成で本文全体（または節）を返す呼び出し（全文の再生成・指摘箇所の修正 targeted・節の再生成 section、更新案の同じ経路）は、`generateContent` と同じ **出力の上限 64,000・時間切れ 15 分**にする。今は `generateSimple` の `max(値, 16,000)`・5 分になっている。呼び出し側で「本文を返す呼び出し」であることを渡す形でよい（例 `generateSimple(…, { maxTokens, kind: 'body' })`）。題名・要約・JSON の短い答えは今どおり。
- 本文（全体・節・targeted の修正後の本文）を返す呼び出しで `stopReason === 'max_tokens'` のときは、**例外にして再生成を失敗として終える**（`regenerate_failed` の通知へ流す）。切れた本文に免責文を足して通さない。`callSimpleOpenAI` が `stopReason` を捨てているのを直し、呼び出し側で見られるようにする。`anthropic` のときも同じ扱いにする（今まで見ていなかった穴）。
- 日次の本文の生成（`generateContent`）で `max_tokens` に達したときの今の扱い（途切れの警告）は確かめ、切れた本文が下書きとして通るなら同じく失敗にする（現状を最終報告に書く）。
- 03 の指示書 R9 の「`generateSimple` は `max(値, 16,000)`」は本文を返す呼び出しには当てはまらない（指示書の穴）。

## F2（M1）重複確認で AI が `url_slug` を答えると見逃す

- 生成前の重複確認（`generate-draft.js` の生成前の確認と `checkPreparedDuplicates`）で、答えの `slug` を `topic.slug` だけでなく `topic.url_slug` とも照らす。候補が 1 件のときは、答えが 1 件なら `slug` を問わず `duplicate` を採る。

## F3（M2）差し戻しの失敗通知の条件が狭い

- `regenerate-draft.yml` の失敗通知を `if: failure()` にする（Validate・commit・push の失敗でも通知）。通知の文面で、どの段階で失敗したかが分かるなら添える。

## F4（M3）「API の失敗」の判定が広すぎる

- `contentCallError` などで、その日の生成を終える「API の失敗」を、HTTP 401・403・408・429・5xx・通信の失敗・時間切れに限る。拒否（refusal）・HTTP 400・応答の形が読めない、は「その候補だけの失敗」として次の候補へ進む（取り下げとしては記録しない。R0 のとおり）。
- 同じ候補が翌日も同じ理由で失敗し続けないよう、「その候補だけの失敗」は取り下げとは別の短期の記録（例: 7 日間は選ばない）にするか、今の試行の記録に残して翌日の選定で後ろに回す。【要判断】既定は「7 日間は選ばない」（記録は `data/withdrawn-topics.json` ではなく別のファイル、または段階 `generation-failed-candidate` を除外に使う期限つきにする。Codex が小さい方を選び、最終報告に書く）。

## F5（M4）短縮・部分修正の答えが ```json で囲まれると読めない

- `body-patches.js` の JSON の読み取りを、`target-query.js` の `extractJson` と同じく、コードの囲みを外し最初の `{` から最後の `}`（配列なら `[`〜`]`）を読む形にする。

## F6（M5）ルールの部分修正が数字を直す修正を弾く

- 生成後のルールの部分修正では、**渡したルールの本文（`text`）に出てくる数字**（金額・割合・期限・年）は、新しい文に入ってよいことにする。それ以外の新しい数字は今どおり弾く。
- 直せなかったときの警告に、キー名だけでなく「論点別ルールが未反映: <キー>（該当箇所が現行の制度に合うか確認してください）」の一文を入れる。表の行は今どおり保護（触らない）だが、表に当たる場合は警告に「表の該当行」と書く。

## F7（M6）教育資金のルールを狭めすぎた

- `expired_education_fund_gift` の `match` を、01 の前の当て方（相続・贈与の分野＋贈与・非課税・孫・祖父母などの語）に戻す。全文の書き直しは無くなったので、誤反応の代償は指示の文字数だけ。試験（`test-generation-one-pass.js` の「贈与税の非課税」で入らない期待）も戻す。

## F8（M7）重複確認が失敗すると素通りする

- 生成前の重複確認が、無効にしているときではなく失敗（API の失敗・答えが読めない・`length`）で `skipped` になったときは、1 回だけ再試行する。それでも失敗したら、生成は続けるが、下書きの `review_warning` に「重複確認を実施できませんでした（AI の応答を得られず）」を残す。
