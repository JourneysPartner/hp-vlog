## この作業でいちばん大事なこと

**変えるのは「記事本文に書く式の見た目」だけで、税額計算の中身ではありません。**

消費税10%の内訳は国税7.8%＋地方消費税2.2%で、`7.8／110` は国税分を取り出す正しい式です。
申告書はこの国税分を書く欄になっているので、**計算ロジックとしては正しい**。

変えたいのは、読者が「消費税は10%」と認識しているのに式に `7.8` が出てきて混乱する、という
記事の読みやすさの問題です。したがって:

- 記事本文の表記 → `10／110` / `8／108` に変える（今回の対象）
- 税務シミュレーターなどの内部計算 → **一切変えない**（変えると計算結果が壊れる）
