# 消費税の割戻し計算を「×10／110」で書かせる

## 背景

記事本文で消費税額を割り戻す計算式が、国税分だけを取り出す `7.8／110` で書かれている。

```
税込みの返還等の金額 × 7.8／110

アパレル商品（標準税率10%が適用される商品）の場合、この式を使います。軽減税率（8%）が
適用される商品（飲食料品など）であれば、7.8／110ではなく6.24／108を用います。

【計算例】
税込み110万円の返品を受けた場合：
110万円 × 7.8 ÷ 110 ＝ 7万8,000円
```

（2026-09-22 生成「アパレル卸の返品・シーズン値引、消費税はどう調整する？」より）

## 何が問題か

**計算そのものは誤りではない。** 消費税10%の内訳は国税7.8%＋地方消費税2.2%で、`7.8／110` は
国税分を取り出す正しい式。申告書はこの国税分を書く欄になっている。

問題は**読者の認識と一致しないこと**。読者は消費税率を「10%（軽減は8%）」として認識している。
同じ記事の中で「標準税率10%が適用される商品」と書きながら、式では `7.8` が出てくるため、
読者は「税率が違うのでは」「どちらが正しいのか」と読み違える。

国税分と地方消費税分の切り分けは申告書の記入欄の話であって、読者が判断に使う情報ではない。

## 決まっている方針

消費税額を割り戻す式を本文に書くときは、**国税・地方税を合算した税率**を使う。

| | 従来（国税分のみ） | これから |
|---|---|---|
| 標準税率 | `× 7.8／110` | **`× 10／110`** |
| 軽減税率 | `× 6.24／108` | **`× 8／108`** |

## 付随して直すもの

`100分の78`（消費税額等から国税分を取り出す係数）も本文に書かない。

`10／110` は合計額を出す式、`消費税額等 × 100分の78` は合計額から国税分を取り出す式で、
**計算の階層が違う**。両方を並べると読者は何を控除するのか分からなくなる。

適格返還請求書の税額を使う方法に触れる場合は、係数を出さずに
「請求書に記載した消費税額等を積み上げる」と書く。

## 実測（記事275本）

| | 件数 |
|---|---|
| `7.8／110` 系を書いている記事 | 2本（うち1本は 2026-09-22 生成分で手直し済み） |
| `100分の78` 系を書いている記事 | 0本 |

頻度は高くないが、消費税の税額計算に踏み込む記事では必ず出る形。

## 既にある前例（同じ論法のルール）

`scripts/lib/article-prompt-static.js:1144` に、まったく同じ理屈のルールが既にある。
**新しいルールはこれに揃えて書く。**

```
【読者が使う数字だけを書く（制度の内訳を持ち込まない）】
金額には「読者が判断に使う結論の数字」と「その数字がどう組み立てられているか」の
2つがある。記事に書くのは<strong>前者だけ</strong>。
  ❌「104万円（基礎控除62万円＋令和8年・令和9年の特例加算42万円）」
  ✓「令和8年分の基礎控除は104万円です」
制度の内訳・区分の境目・改正の建て付けは、あなたが正しい数字を選ぶための材料であって、
読者が使う情報ではない。
```

国税7.8%・地方消費税2.2%という内訳もこれと同じ性質で、「正しく書くための材料」であって
読者が使う情報ではない。
