美容室の回数券や前受金は、**「受け取った時に売上にするか」「施術した時に売上にするか」**で迷いやすい論点です。この記事を読めば、**受領時売上計上と前受金処理（施術時売上計上）のどちらが自分のサロンに合うか判断できます。**

先に結論をいうと、**美容室の回数券は、まだ施術していない部分を前受金として管理し、施術時に売上計上する考え方が実務上は整理しやすい**です。ただし、券の内容や管理方法によっては注意点もあるため、原則と例外を分けて確認することが大切です。

## 美容室の回数券・前受金の基本的な考え方

国税庁タックスアンサー No.1350「事業所得の課税のしくみ」では、事業所得はその年の総収入金額から必要経費を差し引いて計算するとされています。  
美容室の回数券では、「お金を受け取った事実」と「サービスを提供した事実」がずれるため、**いつ収入としてみるか**が実務上のポイントになります。

美容室でよくあるのは、次の2つの処理です。

- **受領時売上計上**：回数券代を受け取った時点で売上にする方法
- **前受金処理（施術時売上計上）**：受け取った時点では前受金として処理し、実際に施術した時に売上へ振り替える方法

回数券は、販売時点では未提供の施術が残っていることが多いため、**未施術分を前受金として扱う方が、実態には合いやすい**と考えられます。

## 回数券の取り扱いを比較するとどう違うか

### 比較表

| 比較項目 | 受領時売上計上 | 前受金処理（施術時売上計上） |
|---|---|---|
| 正式名称・概要 | 代金受領時に全額を売上計上する | 未施術分は前受金とし、施術時に売上計上する |
| メリット | 記帳が一見シンプル | サービス提供の実態と合わせやすい |
| デメリット | 未施術分まで売上化しやすい | 残回数・未消化額の管理が必要 |
| 向いているケース | 単発メニュー中心で前受がほぼない場合 | 回数券、コース契約、チャージ制がある場合 |
| 向かないケース | 長期利用の券や高額コースが多い場合 | 管理表がなく利用状況を追えない場合 |
| 適用条件の考え方 | 受領時点で提供済みに近い内容かを慎重に確認 | 未提供サービスが残るなら基本的にこちらで整理しやすい |
| 主な注意点 | 二重計上や年分ずれが起きやすい | 帳簿と施術記録を一致させる必要がある |

比較すると、**回数券という商品の性質上、前受金処理の方が一般的に整合しやすい**です。  
一方で、どちらの処理でも、継続して同じ基準で管理できることが重要です。

## 判断するときの3つの軸

### 1. 施術が完了しているか

判断の中心はここです。  
**まだ施術していない部分があるなら、その部分は売上ではなく前受金として考える方が自然**です。

### 2. 回数券の内容が長期にわたるか

5回券、10回券、半年コースのように、利用が将来にまたがるものほど、受領時に全額売上とすると実態とのズレが大きくなります。  
反対に、その場でほぼ消化されるような内容なら、処理は比較的シンプルです。

### 3. 残数管理を継続できるか

前受金処理では、**販売額・利用回数・未消化残高**を追えることが必要です。  
管理表がなければ、施術済み分の売上振替が曖昧になりやすいため、実務ではここが重要です。

## 数値シミュレーション｜100万円分の回数券を販売した場合

たとえば、4月に10回券を合計100万円分販売し、その年のうちに60万円分を施術、40万円分が未消化だったとします。

| 処理方法 | 販売時 | 年内の施術時 | 年末時点 |
|---|---|---|---|
| 受領時売上計上 | 100万円を売上 | 追加処理なし | 売上100万円 |
| 前受金処理 | 100万円を前受金 | 60万円を売上へ振替 | 売上60万円、前受金40万円 |

このケースでは、**その年の課税所得を抑えやすいのは前受金処理**です。未施術の40万円を翌期以降に回せるため、売上と施術実績が一致しやすくなります。  
一方で、受領時売上計上は当年の売上が100万円となるため、利益水準によっては税負担が先に出やすくなります。

ただし、「有利・不利」だけで決めるのは適切ではありません。  
大切なのは、**実際のサービス提供の状況に合った処理になっているか**です。

## どちらを選ぶべきか｜判断フローチャート

以下の順で考えると整理しやすいです。

1. **代金を先に受け取る回数券・コースか**
   - いいえ → 通常の施術時売上で整理しやすいです
   - はい → 次へ

2. **受領時点で施術が完了しているか**
   - はい → 受領時売上計上も検討できます
   - いいえ → 次へ

3. **未施術分の金額や残回数を把握できるか**
   - はい → 前受金処理が向いています
   - いいえ → まず管理体制を整えるのが先です

4. **回数券の利用が月をまたぐ・年をまたぐか**
   - はい → 前受金処理で整理する方が実務上は安全です
   - いいえ → 内容次第で受領時処理の検討余地はあります

## 売上規模・事業形態別の考え方

| サロンの状況 | 向きやすい処理 | 理由 |
|---|---|---|
| 個人経営で単発メニュー中心 | 受領時売上計上も検討可 | 前受取引が少なく、ズレが出にくい |
| 回数券販売がある小規模サロン | 前受金処理 | 未消化残高を管理しやすく、実態に合う |
| 高額コースや長期契約が多いサロン | 前受金処理 | 年度またぎのズレや税務リスクを抑えやすい |
| 家族経営で帳簿担当が分かれている | 前受金処理 | 施術記録と売上の対応関係を確認しやすい |

## 判断を誤った場合のリスクと修正方法

受領時に全額売上計上してしまうと、次のようなリスクがあります。

- 未施術分まで売上に入ってしまう
- 翌月以降の施術で二重計上が起きる
- 月次の売上と実際の施術実績が合わなくなる
- 年をまたぐと申告額のズレにつながる

修正する場合は、まず次の資料をそろえます。

- 回数券の販売一覧
- 利用履歴
- 未消化残高の集計
- 会計帳簿上の売上計上状況

そのうえで、**売上として計上した金額のうち未施術分を前受金へ振り替える**形で見直します。  
すでに確定申告を済ませている場合は、状況に応じて修正申告や更正の請求の検討が必要です。年をまたいで影響する場合や、回数券の販売量が多い場合は、専門家に確認した方が進めやすいです。

## 実務での選び方｜最低限そろえたい管理項目

前受金処理を行うなら、次の管理表があると判断しやすくなります。

| 項目 | 内容 |
|---|---|
| 販売日 | いつ販売したか |
| 顧客名 | 誰に販売したか |
| 券種 | 5回券、10回券など |
| 受領額 | いくら受け取ったか |
| 利用回数 | 何回使ったか |
| 未消化額 | まだ施術していない金額 |
| 失効・返金の有無 | 例外処理の確認用 |

特に、**現金が入ったことと売上計上のタイミングは同じではない**点を、家族やスタッフとも共有しておくと、日々の管理がぶれにくくなります。

## まとめ

美容室の回数券は、**受け取った時点で必ず売上になるわけではありません。**  
未施術分があるなら、前受金として管理し、施術時に売上へ振り替える考え方が実務上は整理しやすいです。

自力で進めやすいのは、販売件数が少なく、残回数が明確に追えるケースです。反対に、年をまたぐ高額コース、返金条件がある券、帳簿と施術記録が一致しないケースでは、早めに確認した方が安全です。
