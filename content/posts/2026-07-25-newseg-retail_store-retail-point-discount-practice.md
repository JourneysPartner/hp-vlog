## ポイント・値引きの売上仕訳、何が論点か

小売店でポイントカードや割引サービスを導入すると、「消費税はどの金額に対して計算するのか」「ポイントを付与したときと使われたときで仕訳はどう変わるのか」という疑問が生まれます。

結論を先に示します。

- <strong>割引・値引き</strong>：値引後の金額が売上高、消費税の課税標準も値引後の金額
- <strong>ポイント付与</strong>：付与時は負債（ポイント引当金など）を計上、利用時に売上値引として処理

以下、典型的な3つのケースを仕訳例で解説します。

---

## ケース1：レジで10%割引した場合

<strong>前提：</strong>定価1,100円（税込）の商品を10%割引し、990円（税込）で販売した。

| タイミング | 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|---|
| 販売時 | 現金 | 990円 | 売上高 | 900円 |
|  |  |  | 仮受消費税 | 90円 |

<strong>ポイント：</strong>課税売上高は値引後の900円（税抜）です。1,000円に対して消費税を計算してしまう誤りが多いので注意してください。

---

## ケース2：ポイントを付与したとき

<strong>前提：</strong>税込1,100円の商品を現金で販売し、購入額の1%（11円相当）のポイントを付与した。

| タイミング | 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|---|
| 販売時 | 現金 | 1,100円 | 売上高 | 1,000円 |
|  |  |  | 仮受消費税 | 100円 |
|  | ポイント費用 | 11円 | ポイント引当金 | 11円 |

<strong>ポイント：</strong>付与時点では売上は満額で計上します。ポイントは「将来の割引義務」として負債（引当金）に計上するのが実務上の一般的な処理です。ポイント費用は販売費として計上します。

---

## ケース3：貯まったポイントを次回購入時に使ったとき

<strong>前提：</strong>税込1,100円の商品を購入する際、前回付与された110円分のポイントを使用し、現金990円・ポイント110円で決済した。

| タイミング | 借方 | 金額 | 貸方 | 金額 |
|---|---|---|---|---|
| 販売時 | 現金 | 990円 | 売上高 | 900円 |
|  | ポイント引当金 | 110円 | 仮受消費税 | 90円 |
|  |  |  | （差額調整） | 110円 |

整理すると、ポイント利用分は売上値引として扱い、課税売上高は<strong>現金受取額990円÷1.1＝900円（税抜）</strong>になります。ポイント引当金は取り崩して消込みます。

<strong>注意点：</strong>ポイント利用時の消費税計算を「1,100円×10%」で処理すると過大計上になります。あくまで実際に受け取った対価（現金＋充当ポイントの合計）が課税標準です。

---

## 業種特有の注意点まとめ

| 論点 | 誤りやすい処理 | 正しい処理 |
|---|---|---|
| 割引時の課税売上 | 定価ベースで消費税計算 | 値引後の実受取額で計算 |
| ポイント付与時 | 付与額を売上から引く | 満額売上＋引当金計上 |
| ポイント利用時 | 定価で売上・消費税計上 | 値引後金額で課税売上計上 |
| インボイス対応 | 値引前の税額を記載 | 値引後の正確な税額を記載 |

インボイス制度（適格請求書等保存方式）のもとでは、ポイント値引後の正確な税額をレシートに記載する必要があります。レジシステムの設定が正しいかどうか、定期的に確認することをおすすめします。

---

## まとめ

- 割引・値引きは<strong>値引後の金額</strong>が課税売上。定価ベースで消費税を計算しない
- ポイント付与時は満額で売上計上し、将来の割引義務を引当金として計上する
- ポイント利用時は売上値引として処理し、課税売上高は実際の受取額ベースで計算する
- インボイス対応では、値引後の税額をレシートに正確に反映させる
