ネットショップを副業で始めて、注文が少しずつ入るようになってきた。売上の数字は管理画面ですぐ見られるのに、確定申告が必要かどうかはよく分からない。そんな状態のまま年末が近づいてくると、次のことが気になってきます。

- 売上がいくらを超えたら申告しないといけないの？
- 利益が出ていなくても申告するの？
- 仕入れや送料はどこまで経費にできる？
- 会社の年末調整だけで終わっていいの？

結論からいうと、判断の材料になるのは売上そのものではなく、必要経費を引いたあとの所得です。給与所得がある人の場合は、ネットショップの所得が20万円を超えるかどうかが一つの分かれ目になります。

## まず結論｜判断の材料は売上ではなく所得

会社員など給与を1か所から受けている場合、ネットショップの所得が20万円以下なら、確定申告は原則として不要です。20万円を超えると申告が必要になります。給与所得がない専業の場合は、所得が所得控除の合計額を超えるかどうかで決まります。

| あなたの状況 | 確定申告 | 見るポイント |
|---|---|---|
| 給与1か所・ネットショップの所得20万円以下 | 原則不要 | 給与の全部が源泉徴収の対象であること |
| 給与1か所・ネットショップの所得20万円超 | 必要 | 所得＝売上−必要経費 |
| 給与収入が2,000万円を超える | 必要 | 副業の金額にかかわらず |
| 給与2か所以上・年末調整されなかった給与収入とネットショップの所得の合計が20万円超 | 必要 | 合計額で判定する |
| 給与所得がない（専業）・所得が所得控除の合計額を超える | 必要 | 令和8年分の基礎控除は合計所得金額に応じて異なり、132万円以下なら104万円、489万円超655万円以下なら67万円、655万円超2,350万円以下なら62万円など |

税金が戻る還付申告は、この表に当てはまらない場合でもできます。源泉徴収された税金が多いときは申告したほうが有利です。

## この記事の対象になる人

国内のECモールやネットショップで、個人として商品を販売している方が対象です。会社員の副業、専業、家族の扶養に入っている方など、立場によって見るポイントが変わります。

会社員の場合は、年末調整で給与の税金が清算されています。そこにネットショップの所得が上乗せされる形になるため、20万円というラインが実務上の分岐になります。専業の場合は、給与の年末調整がないので、所得控除の合計額と所得を比べて判断します。

## よくある3つのケース

ケース1は、会社員がアパレル小物を月に数点ずつ販売している場合です。年間売上120万円、仕入60万円、販売手数料12万円、送料8万円、梱包資材2万円なら、必要経費は82万円、所得は38万円になります。20万円を超えるので確定申告が必要です。

ケース2は、会社員がせどりで売上70万円、仕入55万円、手数料7万円、送料5万円だった場合です。経費の合計は67万円、所得は3万円です。20万円以下なので、所得税の確定申告は原則として不要になります。

ケース3は、専業で売上400万円、経費300万円、所得100万円の場合です。令和8年分の基礎控除は、合計所得金額132万円以下なら104万円です。所得100万円は基礎控除の額を下回るため、所得税はかからず申告も不要となります。

## 申告が必要かを確かめる手順

順番に数字を埋めていくと、自分のケースが判断できます。

1. 年間の売上を集計する。商品代金のほか、送料として受け取った金額も含めます。返品や値引きは差し引きます。
2. 必要経費を集計する。仕入代金、販売手数料、送料、梱包資材、プリンタのインク、撮影用小物など、売上を得るために直接かかった費用です。
3. 売上から必要経費を引いて所得を出す。
4. 給与所得があるかどうかで分岐する。ある場合は20万円と比較し、ない場合は所得控除の合計額と比較します。
5. 一度も帳簿をつけていない場合は、注文履歴とカード明細から1年分を洗い出します。

## 事業所得と雑所得、どちらで申告するか

ネットショップの販売は、小売業などの事業から生ずる所得として事業所得になることがあります。一方、副業として営利を目的に継続して行っている程度なら、業務に係る雑所得として扱われることもあります。どちらも計算式は総収入金額から必要経費を引く形ですが、扱いに差があります。

| 項目 | 事業所得 | 雑所得（業務に係るもの） |
|---|---|---|
| 判定のめやす | 小売業などの事業を営んでいる | 副業として営利を目的に継続して行う |
| 青色申告 | できる | できない |
| 生じた損失 | 他の所得と損益通算できる | 他の所得と損益通算できない |
| 書類 | 収支内訳書などの添付が必要（青色申告書で申告する場合を除く） | 前々年分の収入金額が300万円超で現金預金取引等関係書類の保存、1,000万円超で収支内訳書などの添付 |

実務では、売上の規模よりも「継続性と営利性があるか」で説明を求められることが多くなります。開業届の有無だけで決まるものでもありません。

## 所得の計算例

ケース1の数字を表にすると次のとおりです。

| 項目 | 金額 |
|---|---|
| 売上 | 1,200,000円 |
| 仕入 | 600,000円 |
| 販売手数料 | 120,000円 |
| 送料 | 80,000円 |
| 梱包資材 | 20,000円 |
| 必要経費の合計 | 820,000円 |
| 所得 | 380,000円 |

所得38万円は20万円を超えるため、確定申告が必要です。なお、必要経費になるのは、その年の12月31日までに債務が確定した金額です。支払ったタイミングと計上する年がずれることがあるため、12月分の仕入や手数料の締め日を確認しておくと安全です。

## 間違えやすいポイント

最も多いのは、売上で判断してしまうケースです。管理画面の売上合計が目に入るため、その数字が基準だと思い込みやすくなります。判定に使うのは経費を引いた所得です。

次に多いのが、経費を計上し忘れるケースです。勘定科目が分からないという理由で、仕入や送料をそのままにしておくと、所得が実際より大きく出ます。売上を得るために直接かかった費用は必要経費になります。

生活用の家財を売った分を売上に混ぜてしまう例もあります。生活の用に供している資産の売却による所得は非課税で、確定申告も不要です。副業の販売分とは分けて管理します。

自宅の電気代や通信費を全額経費にするのも行き過ぎです。家事上の費用と業務上の費用が混ざるものは、取引の記録などに基づいて業務部分を明らかに区分できた分だけが必要経費になります。

赤字なら申告しなくてよいと思い込むのも危険です。雑所得の計算で生じた損失は、他の所得と損益通算できません。事業所得として青色申告をしている場合は、純損失を翌年以後3年間繰り越せるなどの取扱いがあります。

## 税理士に相談した方がいいケース

所得が20万円の前後にある場合は判断が割れます。経費の見積もり方で結果が変わるため、早めに確認したほうが安心です。

事業所得と雑所得のどちらで申告するか迷う場合も相談の対象です。損益通算や青色申告の可否など、後から変更しにくい違いがあります。

前々年分の業務に係る雑所得の収入金額が300万円や1,000万円に近づいている場合、書類の保存や添付の要否が変わります。在庫が大きく残っている、複数のモールで販売している、海外向けに発送しているといったケースも、自分だけで結論を出すと後で修正が難しくなります。

## よくある質問

### 売上100万円以下なら申告しなくて大丈夫ですか？

売上の金額では判断できません。必要経費を引いた所得が20万円を超えるかどうかで決まります。売上100万円でも経費が50万円なら所得は50万円で、申告が必要です。

### 所得が20万円以下なら何もしなくていいですか？

所得税の確定申告は原則として不要です。ただし、給与収入が2,000万円を超える場合など、他の要件に当てはまる場合は申告が必要になります。税金が戻る場合は申告できます。

### 家で使っているパソコンやスマホは経費にできますか？

業務に使っている部分が記録などで明らかに区分できれば、その部分だけが必要経費になります。私用と兼用のまま全額を経費にすると、後で説明を求められたときに困ります。

### 在庫が残っているときの仕入れはどう処理しますか？

仕入代金の全額ではなく、その年に販売した分に対応する売上原価として計上します。期末在庫の評価方法にも関わるため、金額が大きい場合は早めに確認してください。

### 赤字の年は申告しないほうが得ですか？

雑所得の損失は他の所得と損益通算できないため、申告しても税負担は減りません。事業所得で青色申告をしている場合は、損失を翌年以後に繰り越せる取扱いがあります。

## まとめ

ネットショップの確定申告が必要かどうかは、売上ではなく所得で判断します。給与所得がある人は所得20万円が分かれ目になり、専業の人は所得控除の合計額との比較になります。必要経費を正確に集計することが、そのまま判定の精度になります。

本記事は情報提供を目的として作成しており、特定の税務判断を推奨するものではありません。実際の税務処理・申告については、税理士等の専門家にご相談ください。個別事情によって結論が異なる場合があります。

所得区分の判断や必要経費の範囲は、扱う商品や販売チャネルによって変わります。「自分のケースではどうなるか」を確認したい場合は、税理士への相談がおすすめです。
