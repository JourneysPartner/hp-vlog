## eBayセラーが手数料処理でつまずく理由

eBayで輸出販売をしているセラーの多くが、確定申告の時期に「手数料の消費税はどう扱う？」と迷います。国内取引と同じ感覚で「消費税がかかる支出だから仕入税額控除できる」と思いがちですが、eBayの手数料は<strong>海外事業者（eBay Inc.）への支払い</strong>であるため、国内消費税の課税対象ではありません。

この記事では、eBay手数料の種類ごとに消費税区分を整理し、実際の仕訳例と申告上の注意点を説明します。

---

## eBayの主な手数料と消費税区分

eBayセラーが支払う手数料には複数の種類があります。それぞれの消費税区分を確認してください。

| 手数料の種類 | 内容 | 消費税区分 |
|---|---|---|
| Final Value Fee（落札手数料） | 売上の一定割合をeBayに支払う | <strong>不課税</strong>（国外取引） |
| Listing Fee（出品手数料） | 一定枠を超えた際の出品料 | <strong>不課税</strong>（国外取引） |
| Promoted Listings（広告費） | eBay内の広告サービス費用 | <strong>不課税</strong>（国外取引） |
| Payoneer送金手数料 | 代金受取・送金時の手数料 | <strong>不課税</strong>（国外取引） |
| 国内配送・梱包材費 | 日本国内で購入する備品等 | <strong>課税</strong>（国内取引） |

<strong>不課税</strong>とは、そもそも消費税の課税対象とならない取引です。eBay Inc.は米国法人であり、役務の提供地が国外とみなされるため、消費税法上の「課税仕入れ」には該当しません（消費税法施行令第6条参照）。したがって、仕入税額控除の対象にもなりません。

## 実際の仕訳例

### ケース①：Final Value Feeが引かれた月次精算

eBayから月次で手数料が引き落とされた場合の仕訳イメージです。

<strong>売上（輸出免税）の計上：</strong>

```
売上高（輸出免税）  50,000円  /  売掛金  50,000円
```

<strong>Final Value Fee（不課税）の計上：</strong>

```
支払手数料（不課税）  6,500円  /  売掛金  6,500円
```

ポイントは、消費税区分を「<strong>不課税</strong>」として記帳することです。「課税仕入れ」や「非課税仕入れ」と混同しないよう注意してください。会計ソフトでは「対象外」「不課税」といった区分を選択します。

### ケース②：Payoneer経由で受け取った場合

Payoneerの手数料も不課税として処理します。

```
普通預金  43,000円             /  売掛金  45,000円
支払手数料（不課税）  2,000円  /
```

## 申告・納税義務との関係

eBayセラーの消費税納税義務の判定は、国税庁タックスアンサー No.6501「納税義務の免除」に基づき、<strong>課税売上高1,000万円</strong>が基準となります。

ここで重要なのは、eBayの輸出売上は<strong>免税売上（輸出免税）</strong>として課税売上高に算入される点です。「免税だから売上に含めなくていい」という誤解が多いのですが、輸出免税取引は消費税法上の「課税資産の譲渡等」に含まれるため、1,000万円の判定対象になります（タックスアンサー No.6551も参照）。

| 確認項目 | 内容 |
|---|---|
| 納税義務の判定 | 輸出売上も含めた課税売上高で1,000万円を超えるか確認 |
| 仕入税額控除 | eBay手数料は不課税のため控除対象外。国内仕入れのみ対象 |
| 輸出免税の証明 | 輸出事実の証明書類（送り状・通関記録等）の保存が必要 |

## 実務上の注意点

<strong>会計ソフトの区分設定を最初に確認する</strong>　freeeやマネーフォワードでは、消費税区分として「課税」「非課税」「不課税（対象外）」を選択できます。eBay手数料を「課税仕入れ」で誤登録すると、仕入税額控除が過大になり修正申告が必要になる場合があります。初期設定の段階で「支払手数料（海外）＝不課税」とルール化しておくと安全です。

<strong>為替換算は取引日レートを使う</strong>　eBayの手数料は米ドル建てで請求されます。円換算は原則として取引日の為替レートを使用し、TTSまたはTTMレートで換算します。月次でまとめて処理する場合は月末レートの使用も実務上認められるケースがありますが、継続適用が前提です。

## まとめ

eBayのプラットフォーム手数料は、海外事業者への支払いのため<strong>不課税</strong>として処理します。仕入税額控除の対象にはなりません。一方、輸出売上は免税売上として課税売上高の判定に算入されるため、売上規模が大きくなるにつれて消費税の納税義務や還付の可否が問題になってきます。手数料区分の誤記帳は修正申告につながるリスクがあるため、会計ソフトの初期設定段階での確認をおすすめします。
