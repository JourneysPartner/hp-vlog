美容サロンを個人事業で営んでいる方がまず押さえるべき結論は、**白色申告でも帳簿付けは必要**であり、**青色申告ではより正式な帳簿付けが求められる**という点です。最低限、毎日の売上と経費を記録し、領収書や請求書を保存できていれば、記帳のスタートラインには立てます。

この記事は、開業したばかりの美容サロンオーナーや、「白色と青色で何が違うのか分からない」という方に向けて書いています。

## 個人事業主の帳簿付けとは何か

帳簿付けとは、事業のお金の動きを記録し、所得（もうけ）を計算できるようにすることです。所得税では、事業所得の金額を正しく計算して申告する必要があり、その前提として記帳と帳簿書類の保存が求められます。

白色申告者の記帳・保存については、**所得税法第232条**などに基づき、国税庁タックスアンサー **No.2080「白色申告者の記帳・帳簿等の保存」** でも整理されています。また、経費の基本は **No.2210「やさしい必要経費の知識」** で確認できます。

### 帳簿付けの全体像

| 項目 | 白色申告 | 青色申告 |
|---|---|---|
| 申告方法 | 白色申告 | 青色申告承認申請書の提出が必要 |
| 記帳の水準 | 簡易な方法でも可 | 原則として複式簿記（貸借で記録する方法）が中心 |
| 主な帳簿 | 売上帳、経費帳、現金出納帳など | 仕訳帳、総勘定元帳、現金出納帳、売掛帳など |
| 保存 | 帳簿・書類の保存が必要 | 同様に保存が必要 |
| 実務負担 | 比較的軽い | やや重いが管理しやすい |

## 個人事業主の帳簿付けは誰が対象か

結論からいうと、**美容サロンを個人事業として運営しているなら、白色・青色を問わず対象**です。

「売上が少ないから不要」「開業したばかりだからまだいい」という理解は誤解です。開業直後でも、売上が発生し、経費を使っているなら、その内容を記録しておく必要があります。特にサロン業では、施術売上、店販、家賃、水道光熱費、材料費、広告費など、お金の流れが細かく分かれるため、早めに型を作っておくことが大切です。

## 個人事業主は白色と青色で帳簿付けをどう変えるべきか

原則として、白色は「最低限の記録を漏れなく続けること」、青色は「より正確な帳簿体系にすること」が違いです。

### 白色申告の最低限の記帳ルール

白色申告では、日々の取引を簡易に記録する方法が一般的です。最低限、次の内容を押さえてください。

- 売上の日付・金額・内容
- 経費の日付・支払先・金額・内容
- 領収書、請求書、レシートの保存
- 通帳やカード明細との突合（数字合わせ）

美容サロンであれば、売上は「施術売上」「店販売上」程度に分けるだけでも十分実務的です。経費もまずは「家賃」「材料費」「消耗品費」「広告宣伝費」「水道光熱費」「通信費」など、よく使う科目に絞ると続けやすくなります。

### 青色申告の最低限の記帳ルール

青色申告では、青色申告特別控除を受ける前提として、帳簿の整備が重要になります。特に高い控除額を目指す場合は、**複式簿記**での記帳が基本です。

複式簿記とは、たとえば「現金で材料を買った」取引を、「材料費が増えた」「現金が減った」と二面で記録する方法です。これにより、利益だけでなく現金残高や未回収売上も把握しやすくなります。

実務上は、会計ソフトを使えば複式簿記の知識が深くなくても入力しやすい場合があります。青色申告にするなら、最初からソフト前提で運用した方が現実的です。

次のチェックで、最低限の対応を確認してみてください。

| チェック項目 | はい / いいえ |

| 白色でも帳簿付けが必要だと理解している |  |
| 売上を毎日または定期的に記録している |  |
| 経費を科目ごとに分けて記録している |  |
| レシートや請求書を保存している |  |

3つ以上「いいえ」がある場合は、申告時に慌てやすいため、まずは記録の方法を固めるのがおすすめです。

## よくある誤解と実務上の注意点

### 白色申告ならレシート保存だけでよい、は誤解です

レシート保存は大切ですが、それだけでは足りません。**何に使ったのかを帳簿に記録して初めて経費計上しやすくなります。** 国税庁タックスアンサー No.2080 でも、白色申告者に記帳と保存が必要であることが示されています。

### 事業用と私用の混在は後で困りやすいです

美容サロンでは、個人の買い物とサロン用品の購入が同じカード明細に混ざることがあります。実務上は、事業専用の口座やカードを分けるだけで、記帳の負担がかなり下がります。

### 電子データの保存にも注意が必要です

請求書や領収書をメールやネットで受け取る場合、**電子帳簿保存法**の対象になることがあります。紙で印刷して終わりではなく、電子データのまま保存が必要になる場面もあるため、受け取り方法は確認しておきたいところです。

## 自分でできる範囲と相談が必要になる境目

売上が比較的単純で、現金・カード売上の件数も多すぎず、経費の内容も一般的な範囲であれば、自分で記帳を始めやすいです。まずは白色でも青色でも、毎月ためずに入力することが最優先です。

一方で、次のような場合は早めに相談した方が整理しやすくなります。

- 青色申告に切り替えたい
- 家事按分（自宅兼サロンの家賃や光熱費の按分）がある
- スタッフ給与や外注費が発生している
- 消費税の届出や判定が気になっている
- 現金売上と予約サイト入金の管理が合わない

このあたりからは、帳簿付けそのものより「どの処理が正しいか」の判断が必要になりやすいです。

## まとめ

個人事業主の帳簿付けは、白色なら不要というものではありません。白色は簡易でも記録と保存が必要で、青色はより正式な帳簿が求められます。美容サロンオーナーの方は、まず「売上を記録する」「経費を分ける」「証憑を残す」の3点から始めれば、最低ラインは押さえやすくなります。
