## この記事でわかること

「相続税がかかるかどうか、生前に自分で確認できるだろうか？」と感じている方に向けて、財産評価を進めるための全体像と判断軸を整理します。

結論から言えば、財産評価は <strong>①財産の洗い出し→②種類別の評価方法の確認→③課税財産の合計額の試算</strong> という3つのステップで進めるのが基本です。全体像を把握したうえで、自分で進められる部分と専門家に委ねるべき部分を分けることが、生前準備を効率よく進めるポイントになります。

---

## そもそも財産評価が必要な理由

相続税は「亡くなった方が持っていた財産の総額」をもとに計算します（国税庁タックスアンサー No.4152「相続税の計算」）。財産の総額が基礎控除額（3,000万円＋600万円×法定相続人数）を超えると、相続税の申告・納税が必要になります。

生前に財産評価を把握しておくメリットは主に3つです。

- 相続税がかかるかどうかを事前に見通せる
- 納税資金の準備や生前贈与などの対策を検討できる
- 相続発生後に慌てず手続きを進められる

財産評価は相続発生後でも行いますが、生前であれば時間的余裕を持って対策を講じることができます。

---

## ステップ1：財産の洗い出し

まず、どのような財産があるかを一覧にします。「財産」には、現金や預貯金だけでなく、プラスの財産（課税財産）とマイナスの財産（債務・葬式費用）の両方が含まれます。

### 課税対象になる主な財産

| 財産の種類 | 具体例 |
|---|---|
| 不動産 | 自宅・土地・賃貸用物件など |
| 金融資産 | 預貯金・株式・投資信託・生命保険金（※） |
| 動産 | 自動車・貴金属・美術品など |
| 事業用財産 | 非上場株式・営業権・事業用設備など |
| その他 | ゴルフ会員権・貸付金・未収金など |

（※）生命保険金は「500万円×法定相続人数」の非課税枠があります。

### 控除できる主な債務・費用

| 項目 | 具体例 |
|---|---|
| 借入金 | 住宅ローン・事業用借入金など |
| 未払費用 | 未払税金・未払医療費など |
| 葬式費用 | 通夜・告別式の費用など |

<strong>実務メモ：</strong>財産の洗い出しには、通帳・不動産登記簿・証券口座の残高証明書・保険証券などの書類が手がかりになります。生前のうちに「財産目録」を作成しておくと、相続発生後の家族の負担を大きく減らすことができます。

---

## ステップ2：財産の種類別に評価方法を確認する

財産の種類によって評価方法が異なります。大まかに把握しておくと、どこが難しいポイントかを判断しやすくなります。

| 財産の種類 | 評価方法の概要 | 難易度 |
|---|---|---|
| 現金・預貯金 | 残高そのまま（外貨は相続時の為替換算） | 低 |
| 上場株式 | 相続開始日前後の終値平均など | 低〜中 |
| 土地（宅地） | 路線価方式または倍率方式 | 中〜高 |
| 建物 | 固定資産税評価額をベースに算定 | 低〜中 |
| 賃貸用不動産 | 借家権割合・借地権割合を考慮した評価 | 高 |
| 非上場株式 | 類似業種比準方式・純資産価額方式など | 高 |
| 生命保険金 | 受取額から非課税枠を控除 | 低〜中 |

### 土地の評価：路線価方式と倍率方式

土地の評価で最もよく使われるのが路線価方式です。路線価（国税庁が毎年公表する、道路に面した土地1㎡あたりの価格）に地積を掛け、形状補正などを加えて計算します。路線価が設定されていない地域では倍率方式（固定資産税評価額×一定の倍率）が使われます。

<strong>実務メモ：</strong>土地は「広い・形が複雑・借地・賃貸に出している」などの事情があると評価額が変わり、計算が複雑になります。自宅の土地だけであれば路線価をもとにおおよその試算はできますが、複数の土地や賃貸物件がある場合は専門家に依頼するほうが確実です。

### 非上場株式の評価

中小企業の経営者やその家族にとって、自社株式の評価は特に注意が必要です。評価方法は会社の規模や業種によって異なり、類似業種比準方式・純資産価額方式・またはその折衷方式が使われます。生前に評価額を試算しておくと、株式の分散や贈与などの対策を検討しやすくなります。

---

## ステップ3：課税財産の合計額を試算する

各財産の評価額が出たら、合計してみます。

```
課税財産の合計額 ＝ プラスの財産（評価額合計）－ 債務・葬式費用
```

この合計額が基礎控除額（3,000万円＋600万円×法定相続人数）を超えると、相続税の申告が必要になります。

<strong>試算の例（参考）</strong>

| 項目 | 金額 |
|---|---|
| 不動産（土地・建物） | 4,500万円 |
| 預貯金・株式 | 1,200万円 |
| 生命保険金（非課税控除後） | 300万円 |
| 合計（課税財産） | 6,000万円 |
| 債務（住宅ローン残債） | △500万円 |
| 課税価格の合計 | 5,500万円 |
| 基礎控除（相続人3人の場合） | 4,800万円 |
| 課税遺産総額 | 700万円 |

この例では課税遺産総額が生じるため、相続税の申告が必要になります。

<strong>実務メモ：</strong>この段階では「申告が必要かどうかの大まかな見当をつける」ことが目的です。実際の申告では各種特例（小規模宅地等の特例・配偶者の税額軽減など）の適用によって税額が変わる場合があります。試算だけで判断を終わらせず、特例の要否まで確認することが重要です。

---

## 特例の有無で結論が変わることがある

財産評価の試算で「申告が必要そう」と感じた場合でも、特例の活用により税額が大きく下がったり、実質ゼロになったりする場合があります。

| 特例の名称 | 概要 | 参考 |
|---|---|---|
| 小規模宅地等の特例 | 自宅の土地などの評価額を最大80%減額 | No.4124 |
| 配偶者の税額軽減 | 配偶者が相続した財産の一定額まで税額がかからない | No.4158 |

逆に、「合計額が基礎控除を下回るから大丈夫」と判断した場合でも、生前贈与の加算（相続開始前の一定期間内の贈与財産は相続財産に加算される）を見落とすと試算がずれることがあります。

## 自分で進められる範囲・専門家に相談すべき範囲

| 状況 | 判断の目安 |
|---|---|
| 財産が預貯金・上場株式のみ | 残高・終値をもとに自分で試算しやすい |
| 自宅の土地が1筆のみ | 路線価を調べればおおよその試算は可能 |
| 不動産が複数・賃貸物件あり | 評価が複雑になるため専門家への相談を推奨 |
| 非上場株式（自社株）がある | 評価方法が難しく、早期に専門家へ |
| 生前贈与を繰り返している | 加算の対象期間・金額の確認が必要 |
| 相続人が多い・遺産分割が複雑 | 特例の適用要件に影響するため専門家へ |

財産評価の全体像をつかんだうえで、「複雑な部分だけ専門家に依頼する」という進め方が、時間とコストの両面で現実的な選択肢になります。

---

## まとめ

生前の財産評価は、次の3ステップで進めるのが基本です。

1. 財産・債務を洗い出して一覧にする
2. 財産の種類ごとに評価方法を確認し、評価額を試算する
3. 課税財産の合計額を基礎控除と比べて、申告の要否を判断する

現金・預貯金・上場株式だけの方は比較的自力で進めやすい一方、不動産が複数ある場合や非上場株式を保有している場合は、評価方法が複雑になるため早めに専門家に相談することをおすすめします。また、試算の結果だけで結論を出さず、小規模宅地等の特例や配偶者の税額軽減などの適用可否まで確認することが重要です。
