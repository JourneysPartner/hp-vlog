## この記事でわかること

親や配偶者が亡くなった後、「準確定申告」という手続きが必要になることがあります。通常の確定申告とは異なり、<strong>期限は亡くなった日の翌日から4ヶ月以内</strong>と短く、相続手続きと並行して進めなければなりません。

この記事では、準確定申告を実務で進めるにあたって「何を集めるか」「どの順番で動くか」「ミスしやすい点はどこか」を具体的に整理します。

---

## 準確定申告が必要になるケース

亡くなった方（被相続人）が生前に次のいずれかに該当していた場合、原則として準確定申告が必要です。

| 該当する状況 | 具体例 |
|---|---|
| 給与が2か所以上あった | 再雇用と年金を同時受給していた |
| 給与収入が2,000万円超だった | 現役の高収入役員など |
| 不動産収入があった | 賃貸アパート・土地の貸し付け |
| 事業収入があった | 個人事業主・農業など |
| 医療費控除等を受けたかった | 年間の医療費が高額だった |
| 年金受給者で他の収入もあった | 年金＋不動産収入など |

<strong>給与所得のみで年末調整が済んでいた方は、原則として準確定申告は不要</strong>です。ただし、高額医療費の還付を受けたい場合など、申告することで税金が戻るケースもあります。申告が不要かどうかを迷ったら、一度専門家に確認することをおすすめします。

---

## 実務の進め方：3つのステップ

### ステップ1　書類を集める（死亡後すぐに着手）

準確定申告に必要な書類は、通常の確定申告と重なるものが多いですが、被相続人本人が取得できないため<strong>相続人が代わりに収集</strong>します。

| 書類の種類 | 主な入手先 | 備考 |
|---|---|---|
| 源泉徴収票（給与・年金） | 勤務先・日本年金機構 | 死亡後に発行依頼が必要 |
| 不動産収入の明細 | 管理会社・賃貸契約書 | 1月1日〜死亡日分 |
| 医療費の領収書 | 自宅保管・医療機関 | 生前分をまとめる |
| 生命保険料控除証明書 | 保険会社 | 10月頃送付のもの |
| マイナンバー関連書類 | 市区町村 | 被相続人・相続人分 |
| 前年の確定申告書の控え | 自宅・税務署 | 収入・控除の確認に使う |

<strong>実務メモ：</strong>年金の源泉徴収票は死亡後に日本年金機構から送付されるケースと、相続人が請求しないと届かないケースがあります。早めに日本年金機構（ねんきんダイヤル）へ問い合わせることを推奨します。

---

### ステップ2　所得と控除を集計する（死亡日までの期間分）

準確定申告の対象期間は<strong>1月1日から死亡日まで</strong>です。年の途中で亡くなった場合、年間ではなくその期間分だけを集計します。

<strong>確認すべき所得の種類：</strong>

- 給与所得（1月〜死亡月の給与）
- 公的年金等の雑所得（受給分のみ）
- 不動産所得（賃料収入から必要経費を差し引いたもの）
- 事業所得（個人事業主だった場合）

<strong>使える控除の注意点：</strong>

医療費控除・社会保険料控除・生命保険料控除などは、死亡日までに支払ったものが対象です。<strong>死亡後に相続人が支払った医療費は、被相続人の準確定申告では控除できません</strong>（相続債務として相続税の計算で考慮することになります）。

---

### ステップ3　申告書を作成・提出する

準確定申告書は<strong>相続人全員が連署</strong>して提出するのが原則です（相続人が複数いる場合）。提出先は被相続人の住所地を管轄する税務署です。

| 項目 | 内容 |
|---|---|
| 提出書類 | 所得税の確定申告書（準確定申告用付表を添付） |
| 期限 | 相続開始を知った日の翌日から4ヶ月以内 |
| 提出先 | 被相続人の住所地の税務署 |
| 提出方法 | 窓口・郵送・e-Tax（相続人がID取得済みの場合） |

## よくある間違いと注意点

### 間違い1　期限を「相続税申告と同じ10ヶ月」と勘違いする

相続税の申告期限は10ヶ月ですが、準確定申告の期限は<strong>4ヶ月</strong>です。早々に動き出さないと間に合わなくなります。

### 間違い2　相続人が複数いるのに1人だけで提出しようとする

相続人が複数いる場合、原則として連署が必要です。ただし、他の相続人が署名しない場合でも、申告書に「他の相続人の氏名・住所」を記載した上で単独提出は可能です。この場合、提出した相続人は他の相続人に申告内容を通知する義務があります。

### 間違い3　還付金の受取口座を確認しない

還付が発生する場合、被相続人名義の口座はすでに凍結されていることがあります。<strong>還付金は相続人名義の口座で受け取る</strong>必要があるため、申告書に記載する口座を確認しておきましょう。

| 確認事項 | 済／未 |
|---|---|
| 申告が必要かどうかを確認した | ☐ |
| 源泉徴収票（給与・年金）を取り寄せた | ☐ |
| 医療費の領収書を1月〜死亡日分まとめた | ☐ |
| 不動産・事業の収支を整理した | ☐ |
| 相続人全員に連署の協力を依頼した | ☐ |
| 還付金受取用の相続人名義口座を確認した | ☐ |
| 期限（4ヶ月以内）を確認・手帳に記録した | ☐ |

## 税理士に相談した方がよいケース

次のような場合は、早めに税理士へ相談されることをおすすめします。

- 被相続人が個人事業主・不動産オーナーだった（収支計算が複雑）
- 相続人が複数いて意思疎通がスムーズでない
- 死亡日が12月末〜1月初めで期限が非常に短い
- 医療費や保険料の控除をどこまで計上できるか判断が難しい
- 準確定申告と相続税申告の両方を並行して進める必要がある

## まとめ

準確定申告は、<strong>亡くなってから4ヶ月以内</strong>という短い期限の中で、書類収集・所得集計・申告書作成を進める必要があります。相続手続きと並行するため、できるだけ早く動き始めることが重要です。まずは「申告が必要かどうかの確認」と「源泉徴収票の取り寄せ」から着手してください。
